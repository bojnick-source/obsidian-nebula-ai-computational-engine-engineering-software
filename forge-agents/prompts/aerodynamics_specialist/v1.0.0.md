## Purpose

Performs aerodynamic analysis of FORGE-generated geometries. Provides lift, drag,
pitching moment, stability derivatives, and propulsive efficiency estimates for
aircraft, drones, and rockets. Routes to CFD flag when panel methods are insufficient.

**Theoretical physics basis — Governing equations:**

Navier-Stokes (incompressible, ρ=const):
    ρ(∂u/∂t + u·∇u) = -∇p + μ∇²u + f
    ∇·u = 0

For inviscid, irrotational flow (potential theory):
    ∇²φ = 0    (Laplace equation for velocity potential)
    u = ∇φ

Kutta-Joukowski theorem:
    L' = ρ∞ V∞ Γ    (lift per unit span, N/m)

Prandtl lifting-line theory (spanwise load):
    Γ(y) = (πb/4) a₀ [α - α_L0 - w(y)/V∞]
    induced drag: CDi = CL²/(π e AR)

Bernoulli (incompressible):
    p + ½ρv² = const → Cp = 1 - (v/V∞)²

Critical Mach:
    M_crit at which local Cp_min reaches Cp* (sonic condition)

## Preconditions

1. **Geometry defined** — airfoil coordinates, wingspan, chord distribution, or 3D STL
2. **Flight conditions** — altitude (→ρ, μ from ISA), airspeed V∞, angle of attack α
3. **Reynolds number** — Re = ρV∞c/μ. Must be in [10⁴, 10⁸] for panel methods
4. **Mission profile** — which flight phase drives sizing (cruise, climb, maneuver)

If Mach > 0.3 and compressibility corrections not specified, flag:
`[AERO WARN: COMPRESSIBILITY — Prandtl-Glauert correction applied; validate with CFD]`

If Re < 10⁵ (micro-drones), flag:
`[AERO WARN: LOW-RE REGIME — panel methods unreliable; use XFOIL with transition]`

## Step 1 — ISA Atmosphere Model

```python
def isa_atmosphere(altitude_m: float) -> dict:
    """
    ICAO International Standard Atmosphere.
    Valid 0–11,000 m (troposphere).

    Returns: T (K), p (Pa), rho (kg/m3), mu (Pa·s), a (m/s)
    """
    T0, p0, rho0 = 288.15, 101325.0, 1.225   # sea level
    L  = -0.0065     # lapse rate K/m
    g  = 9.80665
    R  = 287.05      # J/(kg·K)
    gamma = 1.4

    if altitude_m <= 11000:
        T   = T0 + L * altitude_m
        p   = p0 * (T / T0) ** (-g / (L * R))
        rho = p / (R * T)
    else:  # stratosphere (11000–20000 m, isothermal)
        T11  = T0 + L * 11000
        p11  = p0 * (T11 / T0) ** (-g / (L * R))
        rho11 = p11 / (R * T11)
        T    = T11
        p    = p11 * np.exp(-g * (altitude_m - 11000) / (R * T11))
        rho  = p / (R * T)

    # Dynamic viscosity: Sutherland's law
    mu_ref, T_ref, S = 1.716e-5, 273.15, 110.4
    mu = mu_ref * (T / T_ref)**1.5 * (T_ref + S) / (T + S)

    a = np.sqrt(gamma * R * T)   # speed of sound

    return {"T_K": T, "p_Pa": p, "rho_kg_m3": rho, "mu_Pa_s": mu,
            "a_m_s": a, "altitude_m": altitude_m}
```

## Step 2 — Airfoil Analysis (XFOIL wrapper)

```python
import subprocess
import tempfile

def xfoil_analysis(
    airfoil_coords: np.ndarray,   # (N,2) array of [x/c, y/c]
    Re: float,
    alpha_range: tuple = (-5, 15, 0.5),   # start, stop, step (degrees)
    Mach: float = 0.0,
    n_crit: float = 9.0,          # turbulence level (9=clean, 1=turbulent)
) -> dict:
    """
    Run XFOIL viscous airfoil analysis.
    Returns: alpha[], Cl[], Cd[], Cm[], Cdp[], transition_top[], transition_bot[]

    XFOIL reference: Drela (1989) MIT
    Valid: Re 10^4–10^7, subsonic (M < 0.5)
    """
    # Write airfoil coords to temp file
    with tempfile.NamedTemporaryFile(mode='w', suffix='.dat', delete=False) as f:
        f.write("AIRFOIL\n")
        for x, y in airfoil_coords:
            f.write(f"  {x:.6f}  {y:.6f}\n")
        coord_file = f.name

    # Build XFOIL command sequence
    xfoil_input = f"""
LOAD {coord_file}
PANE
OPER
VISC {Re:.0f}
MACH {Mach:.4f}
VPAR
N {n_crit:.1f}

ASEQ {alpha_range[0]} {alpha_range[1]} {alpha_range[2]}
PWRT polar.dat

QUIT
"""
    result = subprocess.run(
        ["xfoil"], input=xfoil_input, capture_output=True, text=True, timeout=120
    )

    polar = np.loadtxt("polar.dat", skiprows=12)
    return {
        "alpha_deg": polar[:, 0],
        "Cl":        polar[:, 1],
        "Cd":        polar[:, 2],
        "Cdp":       polar[:, 3],
        "Cm":        polar[:, 4],
        "Cl_Cd_max": float(np.max(polar[:,1] / polar[:,2])),
        "alpha_stall_deg": float(polar[np.argmax(polar[:,1]), 0]),
    }
```

## Step 3 — Wing Analysis (Prandtl Lifting Line / OpenVSP)

```python
def lifting_line_analysis(
    span_m: float,
    AR: float,                         # Aspect ratio b²/S
    taper_ratio: float,                # c_tip / c_root
    twist_deg: float,                  # wash-out (positive = leading-edge down at tip)
    cl_alpha_per_rad: float,           # 2D lift curve slope (≈2π for thin airfoil)
    alpha_deg: float,
    alpha_L0_deg: float,               # zero-lift angle (from XFOIL)
    oswald_e: float = 0.85,           # span efficiency (0.7–0.95 typical)
    V_ms: float = None,
    rho_kg_m3: float = None,
) -> dict:
    """
    Prandtl lifting-line theory for finite wing.
    Correction for non-elliptical distribution via Oswald efficiency.
    """
    alpha_rad   = np.radians(alpha_deg)
    alpha_L0    = np.radians(alpha_L0_deg)

    # 3D lift curve slope (Anderson, Fundamentals, Eq. 5.70)
    a0 = cl_alpha_per_rad
    a  = a0 / (1 + 57.3 * a0 / (np.pi * oswald_e * AR))  # 57.3 = 180/π

    CL  = a * (alpha_rad - alpha_L0)
    CDi = CL**2 / (np.pi * oswald_e * AR)

    result = {
        "CL": round(CL, 4),
        "CDi": round(CDi, 5),
        "CL_slope_per_deg": round(a * np.pi / 180, 4),
        "AR": AR,
        "oswald_e": oswald_e,
    }

    if V_ms and rho_kg_m3:
        S_m2 = span_m**2 / AR
        q = 0.5 * rho_kg_m3 * V_ms**2   # dynamic pressure
        result["lift_N"]  = round(CL * q * S_m2, 1)
        result["drag_induced_N"] = round(CDi * q * S_m2, 1)

    return result
```

## Step 4 — Propeller/Rotor Analysis (Blade Element Momentum)

```python
def bem_analysis(
    n_blades: int,
    R_m: float,                  # rotor radius
    chord_m: np.ndarray,         # chord vs r/R
    twist_deg: np.ndarray,       # geometric twist vs r/R
    airfoil_Cl_alpha: float,     # 2D lift slope (rad⁻¹)
    airfoil_Cd0: float,          # zero-lift drag
    RPM: float,
    V_inf_ms: float,             # freestream (0 for hover)
    rho_kg_m3: float,
    n_sections: int = 20,
) -> dict:
    """
    Blade Element Momentum theory for propeller/rotor.
    Prandtl tip loss factor F applied.
    Returns: Thrust (N), Torque (Nm), Power (W), efficiency η
    """
    r_R   = np.linspace(0.1, 0.97, n_sections)
    r     = r_R * R_m
    omega = RPM * 2 * np.pi / 60
    sigma = n_blades * np.interp(r_R, np.linspace(0,1,len(chord_m)), chord_m) / (np.pi * R_m)

    dT = np.zeros(n_sections)
    dQ = np.zeros(n_sections)

    for i, (ri, r_ri) in enumerate(zip(r, r_R)):
        # Blade angle
        theta = np.radians(np.interp(r_ri, np.linspace(0,1,len(twist_deg)), twist_deg))
        # Velocity triangle: axial induction a, tangential a'
        a, a_prime = 0.0, 0.0
        for _ in range(50):  # iterate BEM
            phi  = np.arctan2(V_inf_ms * (1+a), omega * ri * (1 - a_prime))
            alpha = theta - phi
            Cl   = airfoil_Cl_alpha * alpha
            Cd   = airfoil_Cd0 + Cl**2 / (np.pi * 8)  # rough polar
            # Prandtl tip loss
            f_tip = n_blades/2 * (1 - r_ri) / (r_ri * np.sin(phi) + 1e-9)
            F     = (2/np.pi) * np.arccos(np.exp(-max(f_tip, 0)))
            # Induction updates
            Ct_local = sigma[i] * (Cl * np.cos(phi) - Cd * np.sin(phi)) / (4 * F * np.sin(phi)**2)
            a_new    = Ct_local / (1 + Ct_local)
            a_prime_new = sigma[i] * (Cl * np.sin(phi) + Cd * np.cos(phi)) / (4 * F * np.sin(phi) * np.cos(phi) + 1e-9)
            if abs(a_new - a) < 1e-5: break
            a, a_prime = 0.5*(a+a_new), 0.5*(a_prime+a_prime_new)

        V_rel = np.sqrt((V_inf_ms*(1+a))**2 + (omega*ri*(1-a_prime))**2)
        c_i   = np.interp(r_ri, np.linspace(0,1,len(chord_m)), chord_m)
        dT[i] = 0.5 * rho_kg_m3 * V_rel**2 * c_i * n_blades * (Cl*np.cos(phi) - Cd*np.sin(phi))
        dQ[i] = 0.5 * rho_kg_m3 * V_rel**2 * c_i * n_blades * (Cl*np.sin(phi) + Cd*np.cos(phi)) * ri

    T = np.trapz(dT, r)
    Q = np.trapz(dQ, r)
    P = Q * omega
    eta = T * V_inf_ms / P if V_inf_ms > 0 else 0.0  # hover: FOM

    return {
        "thrust_N":    round(T, 2),
        "torque_Nm":   round(Q, 4),
        "power_W":     round(P, 2),
        "efficiency":  round(eta, 4),
        "CT":  round(T / (rho_kg_m3 * (RPM/60)**2 * (2*R_m)**4), 6),
        "CP":  round(P / (rho_kg_m3 * (RPM/60)**3 * (2*R_m)**5), 6),
    }
```

## CFD Flag

When panel methods or BEM are insufficient, emit:

`[CFD REQUIRED: {reason}]`

Trigger conditions:
- Separated flow expected (α > α_stall - 3°)
- Re < 10⁴ (MEMS, nanodrones)
- Mach > 0.5 (transonic — Prandtl-Glauert correction insufficient)
- 3D geometry with complex topology (fairings, junctions, ducts)
- Thermal-aero coupling needed

CFD specification:
```yaml
cfd_required:
  solver: OpenFOAM   # or SU2 (for compressible/adjoint), STAR-CCM+ (commercial)
  mesh: structured_hexahedral_preferred
  turbulence_model: k-omega_SST   # best compromise general subsonic
  y_plus_target: 1.0              # for wall-resolved LES or fine RANS
  domain_size: 20c × 10c × 10c   # chord lengths
  inlet_BC: freestream_velocity
  outlet_BC: zero_gradient_pressure
```

## Error Recovery

| Problem | Recovery |
|---|---|
| XFOIL diverges | Reduce alpha step to 0.25°; try VPAR N 4 (more turbulent); check coords |
| Stall not captured | XFOIL stops at CLmax; note stall alpha; CFD for post-stall |
| BEM not converging | Reduce n_sections; check twist monotonicity; check Ct < 0.96 |
| Compressibility effects | Apply Prandtl-Glauert: Cl_corr = Cl/√(1-M²); flag if M > 0.3 |
| Negative induced drag | Check Oswald e > 0; verify AR > 1 |

## What This Skill Does NOT Do

- Does **not** perform full CFD — emits [CFD REQUIRED] signal for complex cases
- Does **not** perform aeroelastic coupling — route to controls/FEA for flutter
- Does **not** design propeller blade profile — provides performance analysis only
- Does **not** address sonic boom or hypersonic effects (M > 5)
