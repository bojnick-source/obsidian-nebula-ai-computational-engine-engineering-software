## Purpose

Linear algebra analysis for FORGE systems. Provides matrix decompositions,
eigenvalue analysis, singular value decomposition, tensor operations, and
numerical conditioning assessment. Used by virtually all computational agents
(FEA stiffness assembly, CFD linearisation, control system design, ML features).

**Core formalism:**

Vector space: set V with addition + scalar multiplication satisfying 8 axioms
Basis: linearly independent spanning set. dim(V) = number of basis vectors.
Linear map T:V→W represented by matrix A ∈ ℝ^{m×n}

Fundamental theorem (rank-nullity):
    rank(A) + nullity(A) = n

Four fundamental subspaces:
    col(A)   = range of A (column space)    dim = rank(A)
    null(A)  = kernel of A                  dim = nullity(A) = n - rank(A)
    row(A)   = col(Aᵀ)                     dim = rank(A)
    null(Aᵀ) = left null space             dim = m - rank(A)

SVD: A = UΣVᵀ (U: left singular vectors, Σ: singular values, V: right)
Eigendecomposition: Av = λv → A = PΛP⁻¹ (diagonalisable A)
Symmetric A = AᵀA: real λ, orthogonal eigenvectors (spectral theorem)

## Step 1 — Matrix Decompositions

```python
import numpy as np
from scipy import linalg

def matrix_analysis(A: np.ndarray) -> dict:
    """
    Complete matrix analysis: rank, condition, decompositions.
    Flags ill-conditioning before any solve.
    """
    m, n = A.shape
    rank = np.linalg.matrix_rank(A)

    # SVD
    U, sigma, Vt = np.linalg.svd(A, full_matrices=False)

    # Condition number
    cond = sigma[0] / max(sigma[-1], 1e-300)
    if cond > 1e12:
        print(f"[WARN: ILL-CONDITIONED] condition number = {cond:.2e}")
        print("Numerical solution may lose {:.0f} decimal digits of accuracy".format(
            np.log10(cond)))

    # Null space (right singular vectors for σ < tol)
    tol = max(m, n) * sigma[0] * np.finfo(float).eps
    null_basis = Vt[sigma < tol].T

    result = {
        "shape": (m, n),
        "rank": rank,
        "nullity": n - rank,
        "condition_number": cond,
        "singular_values": sigma,
        "is_full_rank": rank == min(m, n),
        "null_space_dim": n - rank,
        "null_basis": null_basis if null_basis.size > 0 else None,
    }

    # QR decomposition
    Q, R = np.linalg.qr(A)
    result["QR_Q"] = Q
    result["QR_R"] = R

    # Eigenvalues (square matrices only)
    if m == n:
        eigenvalues, eigenvectors = np.linalg.eig(A)
        result["eigenvalues"] = eigenvalues
        result["eigenvectors"] = eigenvectors
        result["spectral_radius"] = max(abs(eigenvalues))
        result["is_positive_definite"] = all(np.real(eigenvalues) > 0)

    return result


def least_squares_solve(
    A: np.ndarray, b: np.ndarray, regularise: float = 0.0,
) -> dict:
    """
    Least-squares solution min||Ax-b||₂.
    Tikhonov regularisation: min||Ax-b||² + λ||x||² → x=(AᵀA+λI)⁻¹Aᵀb
    Use regularise > 0 for ill-conditioned A.

    Returns: x_hat, residual norm, effective rank
    """
    if regularise > 0:
        n = A.shape[1]
        x_hat = np.linalg.solve(A.T @ A + regularise * np.eye(n), A.T @ b)
    else:
        x_hat, residuals, rank, sv = np.linalg.lstsq(A, b, rcond=None)

    residual = np.linalg.norm(A @ x_hat - b)
    return {"x_hat": x_hat, "residual_norm": residual}
```

## Step 2 — Sparse Linear Systems (FEA Relevance)

```python
from scipy.sparse import lil_matrix, csr_matrix
from scipy.sparse.linalg import spsolve, gmres, cg

def sparse_solve(K: np.ndarray, F: np.ndarray, method: str = "direct") -> dict:
    """
    Solve K·u = F for FEA stiffness matrix K.

    Methods:
    - "direct": scipy spsolve (UMFPACK) — exact for small-medium systems
    - "cg":     Conjugate Gradient — symmetric positive definite K only
    - "gmres":  GMRES — general sparse; needs preconditioner for large K

    Convergence check: ||K·u - F|| / ||F|| < 1e-10
    Typical FEA: n_dof = 10⁴–10⁷; sparse K has O(n) non-zeros
    """
    K_sparse = csr_matrix(K) if not hasattr(K, 'format') else K

    if method == "direct":
        u = spsolve(K_sparse, F)
        error = np.linalg.norm(K_sparse @ u - F) / (np.linalg.norm(F) + 1e-15)

    elif method == "cg":
        u, info = cg(K_sparse, F, tol=1e-12, maxiter=10*K_sparse.shape[0])
        error = np.linalg.norm(K_sparse @ u - F) / (np.linalg.norm(F) + 1e-15)
        if info != 0:
            print(f"[WARN: CG DID NOT CONVERGE] info={info}")

    elif method == "gmres":
        u, info = gmres(K_sparse, F, tol=1e-12)
        error = np.linalg.norm(K_sparse @ u - F) / (np.linalg.norm(F) + 1e-15)

    return {
        "u": u,
        "relative_residual": round(float(error), 15),
        "converged": error < 1e-8,
        "method": method,
    }
```

## Step 3 — Tensor Operations

```python
def tensor_coordinate_transform(
    T_ij: np.ndarray,    # 2nd-order tensor in original coordinates (3×3)
    R: np.ndarray,       # rotation matrix (3×3), R ∈ SO(3)
) -> np.ndarray:
    """
    Second-order tensor transformation:
    T'_{ij} = R_{ik} R_{jl} T_{kl} = R T R^T

    Applications:
    - Stress tensor rotation to principal axes
    - Inertia tensor rotation (rigid body dynamics)
    - Permittivity tensor in anisotropic crystals (photonics)
    """
    return R @ T_ij @ R.T


def principal_stress(sigma_3x3: np.ndarray) -> dict:
    """
    Eigendecomposition of symmetric 3×3 Cauchy stress tensor.
    Returns principal stresses σ1≥σ2≥σ3 and principal directions.

    von Mises: σ_VM = √(½[(σ1-σ2)²+(σ2-σ3)²+(σ3-σ1)²])
    """
    eigenvalues, eigenvectors = np.linalg.eigh(sigma_3x3)   # symmetric → real
    idx = np.argsort(eigenvalues)[::-1]
    sigma_p = eigenvalues[idx]
    dirs    = eigenvectors[:, idx]

    vm = np.sqrt(0.5 * ((sigma_p[0]-sigma_p[1])**2 +
                        (sigma_p[1]-sigma_p[2])**2 +
                        (sigma_p[2]-sigma_p[0])**2))

    return {
        "sigma1_MPa": round(sigma_p[0], 4),
        "sigma2_MPa": round(sigma_p[1], 4),
        "sigma3_MPa": round(sigma_p[2], 4),
        "von_mises_MPa": round(vm, 4),
        "principal_directions": dirs,
    }
```

## Numerical Conditioning Rules

| Condition number κ(A) | Digits lost | Action |
|---|---|---|
| < 10² | 0 | Direct solve fine |
| 10²–10⁸ | 2–8 | Check problem formulation |
| 10⁸–10¹² | 8–12 | Use double-precision; precondition |
| > 10¹² | >12 | Regularise; check physical model |

For FEA: ill-conditioning often indicates unconstrained rigid body motion (missing BC)
or near-zero-energy modes (hourglass in reduced integration).

## Historical Context

Key milestones: Gauss (1820s, least squares) → Cayley (1858, matrix algebra) →
Sylvester (rank, 1851) → Frobenius (eigenvalues, 1878) → Hilbert (infinite-dim,
1900s) → von Neumann (functional analysis, 1940s) → Householder/Francis (QR, 1960s)
→ Golub & Van Loan (numerical stability, 1983) → Trefethen & Bau (modern numerics, 1997)

## Current SOA (2025-2026)

- Randomised SVD (Halko et al. 2011): O(mn log k) vs O(mn min(m,n)) — essential for large matrices
- Tensor decomposition (TensorTrain, HOSVD): quantum chemistry, ML
- GPU-accelerated BLAS (cuBLAS): 1000× speedup for dense operations
- Mixed-precision: FP16 accumulate + FP32 store (transformer inference)
