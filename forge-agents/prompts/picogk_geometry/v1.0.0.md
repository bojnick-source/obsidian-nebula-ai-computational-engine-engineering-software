  "run Noyron", "make the lattice", "build the mesh"

---

## Purpose

Executes PicoGK Python scripts to produce volumetric solid models from
parametric component definitions. Output is a voxel field (VDB) and
optionally a mesh (STL/OBJ) ready for FEA or manufacturing export.

PicoGK only builds what the params file specifies. It does not define
parameters, optimize topology, or validate engineering requirements — those
are `component-generation`, `topology-optimization`, and `simulation-fea`
respectively.

---

## Preconditions

Verify all of these before writing any code:

1. **Params file exists** in vault at
   `projects/{name}/components/{id}_params.py`
2. **PicoGK is installed** — run
   `python -c "import picogk; print(picogk.__version__)"`.
   If it fails: `pip install picogk --break-system-packages` and confirm.
3. **Noyron is available** if biomorphic structures (lattices, bone-like
   infill) are needed — `python -c "import noyron"`. Noyron is the Leap71
   computational geometry library; do not substitute generic lattice infill.
4. **Output directory** for VDB/STL files exists or can be created.
5. **Voxel resolution** is set per the resolution guide below.

If the params file does not exist, call `component-generation` first.
Do not improvise geometry without a spec.

---

## Resolution Guide

PicoGK works in voxels. Voxel size = edge length in mm. Wrong resolution
produces wrong mass, wrong wall thickness, wrong topology.

| Component characteristic | Recommended voxel size |
|---|---|
| Large structural shell > 200 mm, walls > 3 mm | 0.5 mm |
| Medium structural part 50–200 mm, walls 1.5–3 mm | 0.3 mm |
| Fine-feature part < 50 mm or walls < 1.5 mm | 0.15 mm |
| Lattice / biomorphic infill | 0.2 mm (balance detail vs. compute) |
| Final export for manufacturing | 0.1 mm or finer |

Never use a voxel size coarser than 1/5 of the minimum wall thickness.
When uncertain, start at 0.3 mm and refine.

## Step 1 — Read and Validate Params

Load the params file and confirm all required fields are present:

```python
from pathlib import Path
import importlib.util

def load_params(vault_path: str):
    """
    Load component params from vault path.
    Returns params object or raises with clear error.
    """
    spec = importlib.util.spec_from_file_location("params", vault_path)
    module = importlib.util.module_from_spec(spec)
    try:
        spec.loader.exec_module(module)
    except Exception as e:
        raise RuntimeError(
            f"Failed to load params from {vault_path}: {e}\n"
            f"Check that all class attributes have type annotations and defaults."
        )

    # Find the first class ending in 'Params'
    params_class = next(
        (v for k, v in vars(module).items()
         if isinstance(v, type) and k.endswith("Params")),
        None
    )
    if params_class is None:
        raise RuntimeError(
            f"No class ending in 'Params' found in {vault_path}. "
            f"Component-generation must produce a *Params class."
        )
    return params_class()
```

After loading, print all parameter values and derived properties. Verify:

- No `None` values in fields that drive geometry dimensions
- All values are physically plausible (no negative lengths, no zero-thickness walls)
- Interface dimensions match IF-XXX records

If any validation fails, fix the params file — do not work around it in
the geometry script.

## Step 2 — Write the PicoGK Script

Use PicoGK's functional voxel API. Write geometry as composable operations,
not monolithic blobs:

```python
import picogk as pgk
from picogk import Vec3, BBox3

def build_fuselage_shell(params) -> pgk.Voxels:
    """
    Build the fuselage shell as a hollow cylinder with cutouts.

    Strategy: outer solid MINUS inner hollow MINUS interface cutouts.
    This mirrors the physical layup: building around a mandrel.
    """
    # ── Outer shell ───────────────────────────────────────────────────────
    outer = pgk.Voxels(VOXEL_SIZE_MM)
    outer.from_mesh(pgk.cylinder(
        radius=params.max_diameter_m * 1000 / 2,       # m → mm
        height=params.length_m * 1000,
        center=Vec3(0, 0, 0),
    ))

    # ── Inner cavity (subtract) ───────────────────────────────────────────
    inner = pgk.Voxels(VOXEL_SIZE_MM)
    inner.from_mesh(pgk.cylinder(
        radius=params.inner_diameter_m * 1000 / 2,
        height=params.length_m * 1000 + 2,             # +2 mm: clean subtraction
        center=Vec3(0, 0, 0),
    ))

    # ── Shell = outer - inner ─────────────────────────────────────────────
    shell = pgk.boolean_subtract(outer, inner)

    # ── Wing spar cutouts (×2, symmetric) ────────────────────────────────
    for y_offset_mm in [+params.wing_root_spar_cutout_diameter_m * 1000 / 2,
                        -params.wing_root_spar_cutout_diameter_m * 1000 / 2]:
        spar_cutout = pgk.Voxels(VOXEL_SIZE_MM)
        spar_cutout.from_mesh(pgk.cylinder(
            radius=params.wing_root_spar_cutout_diameter_m * 1000 / 2,
            height=params.max_diameter_m * 1000 + 2,   # through-cut
            center=Vec3(0, y_offset_mm, params.length_m * 1000 * 0.35),
            axis=Vec3(1, 0, 0),
        ))
        shell = pgk.boolean_subtract(shell, spar_cutout)

    return shell


def validate_geometry(voxels: pgk.Voxels, params) -> dict:
    """
    Run geometry validation checks.
    Returns {check_name: (passed, got_value, expected_value)}.
    """
    bbox = voxels.bounding_box()
    volume_m3 = voxels.volume() / 1e9          # mm³ → m³
    rho = getattr(params, 'density_kg_m3', 1600.0)
    estimated_mass_kg = volume_m3 * rho

    return {
        "length_within_envelope": (
            abs(bbox.size.z - params.length_m * 1000) < 2.0,
            f"{bbox.size.z:.1f} mm",
            f"{params.length_m * 1000:.1f} ± 2.0 mm",
        ),
        "diameter_within_envelope": (
            abs(bbox.size.x - params.max_diameter_m * 1000) < 2.0,
            f"{bbox.size.x:.1f} mm",
            f"{params.max_diameter_m * 1000:.1f} ± 2.0 mm",
        ),
        "mass_within_budget": (
            estimated_mass_kg <= params.mass_budget_kg,
            f"{estimated_mass_kg:.4f} kg",
            f"≤ {params.mass_budget_kg:.4f} kg",
        ),
        "no_isolated_voxels": (
            voxels.is_connected(),
            "connected",
            "all voxels form single connected body",
        ),
    }
```

Rules:

- Every boolean operation must be verified — check the result is non-empty
  after a subtract.
- Every cutout must overshoot by at least +2 mm to guarantee a clean
  through-cut.
- Geometry must be checked for manifoldness before export.
- Never use hardcoded dimensions — always read from params.

## Step 3 — Run and Validate

Execute the script and capture output:

```python
VOXEL_SIZE_MM = 0.3   # set per resolution guide

if __name__ == "__main__":
    params = load_params("path/to/C-001_params.py")
    voxels = build_fuselage_shell(params)

    checks = validate_geometry(voxels, params)

    print("\n=== GEOMETRY VALIDATION ===")
    all_pass = True
    for name, (passed, got, expected) in checks.items():
        status = "✅ PASS" if passed else "❌ FAIL"
        print(f"  {status}  {name}: got {got}, expected {expected}")
        if not passed:
            all_pass = False

    if not all_pass:
        print("\n⚠️  GEOMETRY FAILED VALIDATION — do not proceed to FEA")
        exit(1)

    output_dir = Path("output")
    output_dir.mkdir(exist_ok=True)
    voxels.to_vdb(str(output_dir / "C-001_fuselage.vdb"))
    voxels.to_stl(str(output_dir / "C-001_fuselage.stl"))
    print(f"\n✅ Geometry written to {output_dir}")
```

If any validation check fails, do not continue. Fix the geometry first.

## Step 4 — Noyron Biomorphic Structures (if required)

Use Noyron for lattice infill, bone-like structures, or organically optimized
geometry. Only call Noyron if `topology-optimization` has explicitly recommended
lattice infill — do not add lattices speculatively.

```python
import noyron as nyr

def add_lattice_infill(outer_shell: pgk.Voxels, params) -> pgk.Voxels:
    """
    Fill the shell interior with a Noyron gyroid lattice.
    Only use when topology-optimization has prescribed lattice infill.
    """
    lattice = nyr.gyroid(
        bounds=outer_shell.bounding_box(),
        cell_size_mm=8.0,
        wall_thickness_mm=0.8,
        voxel_size=VOXEL_SIZE_MM,
    )
    # Intersect lattice with shell interior
    interior = pgk.boolean_subtract(
        pgk.solid_from_bbox(outer_shell.bounding_box(), VOXEL_SIZE_MM),
        outer_shell,
    )
    infilled = pgk.boolean_union(outer_shell, pgk.boolean_intersect(lattice, interior))
    return infilled
```

## Error Recovery

| Problem | Recovery |
|---|---|
| `picogk` import fails | `pip install picogk --break-system-packages`, confirm version |
| Boolean subtract returns empty | Cutter geometry too small or misaligned; increase cutter by +2 mm, re-run |
| `is_connected()` returns False | Use `voxels.separate_components()` to identify disconnected region; investigate before fixing |
| Mass exceeds budget after geometry | Re-examine wall thickness param; flag to user with options — do not silently thin |
| Geometry validation fails | Fix params; never proceed to FEA with failed geometry |
| VDB file > 500 MB | Use coarser resolution for FEA pass; fine resolution only for manufacturing export |
| Noyron not installed | `pip install noyron --break-system-packages`; if unavailable, use solid geometry and note in vault |

## What This Skill Does NOT Do

- Does **not** define component parameters — that is `component-generation`;
  PicoGK only builds what the params file specifies
- Does **not** perform structural analysis — output is the input to
  `simulation-fea`, not a replacement for it
- Does **not** optimize topology — run `topology-optimization` first if
  mass-optimal geometry is required
- Does **not** produce parametric CAD (STEP with feature tree) — VDB/STL is
  mesh-based; exact bores, threads, and radii require `cad-export`
- Does **not** validate engineering requirements — it validates geometry
  against its own params; requirement compliance is `simulation-fea`'s job
