## Purpose

Provides acoustic and vibro-acoustic analysis for FORGE projects. Covers:

- Acoustic source characterisation (propellers, rotors, jets, motors)
- Structural vibration and resonance (modal analysis, frequency response)
- Vibration isolation (mounts, grommets, constrained-layer damping)
- Sound pressure level (SPL) prediction at receiver
- Noise reduction design (enclosures, baffles, acoustic foam)
- Structural acoustic coupling (panel radiation, coincidence frequency)
- Regulatory compliance (FAA noise, OSHA occupational, residential zoning)

## Step 1 — Source Characterisation

For rotating machinery (propellers, fans, rotors):

```python
def blade_pass_frequency(rpm, n_blades):
    """BPF = RPM/60 × N_blades"""
    return (rpm / 60.0) * n_blades

def tip_speed(diameter_m, rpm):
    """V_tip = π × D × RPM/60"""
    import math
    return math.pi * diameter_m * rpm / 60.0

def spl_estimate_propeller(thrust_N, diameter_m, distance_m, n_blades, rpm):
    """
    Empirical propeller noise estimate (Hubbard 1952 / NASA TN D-7021).
    Returns SPL in dBA at distance_m.
    Note: ±5 dB accuracy typical for preliminary sizing.
    """
    # Disk loading W/m²
    import math
    A_disk = math.pi * (diameter_m / 2)**2
    disk_loading = thrust_N / A_disk
    # Approximate empirical correlation
    SPL = 83 + 15 * math.log10(disk_loading / 100) - 20 * math.log10(distance_m)
    return SPL
```

Always state source model assumptions and accuracy limits.

## Step 2 — Propagation

For free-field propagation:

```
SPL(r) = SPL(r_ref) - 20 × log10(r / r_ref)   [spherical spreading]
```

For ground reflection (near-ground operation):

```
SPL(r) = SPL_free + DI_ground    [ground effect, +3 to +6 dB near hard ground]
```

Atmospheric absorption (ISO 9613-1) for distances > 100 m:
```
ΔL_atm = α × r × 10⁻³   [α in dB/km, frequency-dependent]
```

## Step 3 — Structural Resonance Check

For structural panels in the acoustic field:

- Compute natural frequencies: f_n = (π/2) × √(EI / ρA) / L² (Euler beam)
- Check coincidence frequency: f_c = c² / (1.8 × c_L × h) where c_L = plate wave speed
- Flag resonances within ±20% of excitation frequencies
- Recommend damping treatment (CLD, constrained-layer, dynamic absorber)

## Step 4 — Isolation Design

For vibration isolation (equipment on flexible mounts):

```python
def isolation_efficiency(f_excitation, f_natural, zeta=0.05):
    """
    Transmissibility TR = sqrt((1 + (2ζr)²) / ((1-r²)² + (2ζr)²))
    where r = f_excitation / f_natural
    Isolation achieved when r > √2 (TR < 1).
    """
    import math
    r = f_excitation / f_natural
    TR = math.sqrt((1 + (2*zeta*r)**2) / ((1 - r**2)**2 + (2*zeta*r)**2))
    isolation_dB = -20 * math.log10(TR) if TR > 0 else 0
    return TR, isolation_dB
```

Target natural frequency: f_n ≤ f_excitation / (√2 × 1.5) for 6 dB isolation margin.
