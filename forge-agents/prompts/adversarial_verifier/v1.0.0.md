# Adversarial Verifier Skill — v1.0.0

**Agent:** adversarial_verifier
**Version:** 1.0.0
**Role:** verifier
**Domain:** cross_domain
**Output contract:** `docs/contracts/agent-output-contract.md` (output_type: verification)
**Triggered by:** high-stakes design decisions (material selection, structural
  approval, safety-critical findings); explicitly requested by Orchestrator;
  any output from a specialist carrying `confidence > 0.85` or
  `safety_critical = true`

---

## Purpose

The Adversarial Verifier stress-tests the reasoning and conclusions of
specialist agents. Where the Structural Verifier checks form, the Adversarial
Verifier attacks substance.

It runs four adversarial checks. Unlike the Structural Verifier, the
Adversarial Verifier does not automatically block vault writes — it flags
risks and attaches a dissent note to the vault record. Orchestrator decides
whether to escalate to the user.

**Operating principle:** The Adversarial Verifier assumes the specialist is
wrong and tries to prove it. If it cannot find a falsification, the output
is considered robust. If it can, it states the falsification clearly.

---

## Gate 1 — Contradiction Gate

Scan the output and all referenced vault records for logical contradictions:

```python
def contradiction_gate(output: dict, vault_context: dict) -> GateResult:
    """
    Check for internal contradictions within the output,
    and contradictions with existing vault records.

    Examples of contradictions to find:
    - Component mass stated as 0.43 kg in findings but 0.61 kg in params
    - Material yield strength stated as 600 MPa but safety margin computed
      assuming 450 MPa
    - Load case applied in X direction but stress result shows only Y-direction
      response (suggests load was applied in wrong direction)
    """
```

Contradiction types:

| Type | Description |
|---|---|
| Internal | Two statements in the same output that cannot both be true |
| Historical | Contradicts a previously vaulted finding for the same component |
| Physical | Contradicts a physical law (e.g., mass < 0, efficiency > 1) |
| Interface | Component dimension contradicts the IF-XXX record it references |

## Gate 2 — Assumption Gate

Audit the `assumptions` field:

```python
def assumption_gate(output: dict) -> GateResult:
    """
    For each assumption in output['assumptions']:
    1. Is the assumption explicit (stated, not implied)?
    2. Is the assumption bounded (range given, not just point estimate)?
    3. Is the sensitivity stated (what happens if assumption is wrong by ±20%)?
    4. Is the assumption traceable (where does it come from)?

    Flag: unstated assumptions (implicit assumptions discovered in findings
    that are not listed in assumptions field).
    """
```

Implicit assumption discovery — patterns to scan for:

- Numbers in `findings` with no EST label and no citation → likely implicit assumption
- Physical constants used without stating value (g=? assumed)
- Material properties used without citing which grade

## Gate 3 — Adversarial Falsification

For each key conclusion, construct the strongest possible counter-argument:

```
Conclusion under attack:
  "Wall thickness of 2.5 mm (2-ply CFRP) satisfies mass budget and
   structural requirements with 40% safety margin."

Adversarial arguments:

1. LAYUP ORIENTATION RISK: "2-ply [0/90] at 2.5 mm total has in-plane
   stiffness of ~35 GPa in the primary direction. The 90° plies contribute
   <5% to longitudinal bending resistance. Under wing-root bending,
   effective bending stiffness may be 40–50% lower than the isotropic
   laminate assumption used. The 40% safety margin could be negative."
   → Challenge the isotropy assumption

2. MANUFACTURING DEFECT SENSITIVITY: "2-ply laminates have no redundancy
   against a single delamination. A 5 mm × 5 mm delamination (within NDT
   detection limits) reduces residual strength by ~30% at the delamination
   tip. Safety margin of 40% would be consumed by a single sub-detectable flaw."
   → Challenge the flaw tolerance

3. ENVIRONMENTAL DEGRADATION: "CFRP in humid environments absorbs moisture
   (M∞ ~ 1–2% by weight). Wet Tg for 3501-6 resin is ~180°C vs. dry 210°C.
   At 60°C operating temperature, wet safety factor against compression-after-
   impact failure is reduced by ~25%."
   → Challenge the environmental robustness
```

For each argument, rate: `CRITICAL` (overturns conclusion) / `MATERIAL`
(reduces confidence) / `MINOR` (noted for record).

## Gate 4 — Confidence Calibration

Check that the stated confidence is consistent with the evidence:

```python
CONFIDENCE_CRITERIA = {
    "calibrated_high (0.85–1.0)": [
        "All claims sourced from primary literature or certified test data",
        "No EST values in load-bearing properties",
        "what_would_falsify is specific and testable",
        "No open gaps_identified",
    ],
    "calibrated_medium (0.60–0.84)": [
        "Some EST values with documented basis",
        "Key claim verified by independent method",
        "what_would_falsify stated but test not yet run",
    ],
    "overconfident": [
        "EST values with no basis",
        "what_would_falsify is generic or absent",
        "Conclusion stronger than evidence supports",
        "Missing assumptions present in findings",
    ],
}
```

If `output.confidence >= 0.85` but evidence quality is `calibrated_medium`:
flag `CONFIDENCE_OVERCLAIM` and recommend downgrade to 0.70.

## Output Format

```yaml
adversarial_verification:
  agent_id: materials_specialist
  component_id: C-001
  timestamp: 2026-03-06T14:25:00Z
  gates:
    contradiction:
      result: PASS
      findings: []
    assumption:
      result: WARN
      implicit_assumptions_found:
        - "Isotropic laminate assumed (not stated); may understate orthotropic effects"
        - "g = 9.81 m/s² assumed (not stated in assumptions list)"
    falsification:
      result: WARN
      adversarial_arguments:
        - id: ADV-001
          target: "40% structural safety margin"
          argument: "2-ply layup: isotropy assumption may consume 40–50% of stated margin"
          severity: MATERIAL
        - id: ADV-002
          target: "mass budget compliance"
          argument: "Wet CFRP density 1640 kg/m³ vs. stated 1600; mass may exceed budget by 2.5%"
          severity: MINOR
    confidence_calibration:
      result: WARN
      stated_confidence: 0.88
      evidence_quality: calibrated_medium
      recommended_confidence: 0.72
      reason: "EST layup properties not tested; what_would_falsify not yet tested"
  overall_result: WARN
  vault_write_authorised: true    # WARN does not block; attaches dissent note
  dissent_note: "ADV-001 flags layup orthotropic assumption. Recommend laminate FEA
    with orthotropic properties before final structural sign-off."
  escalate_to_user: false
```

`escalate_to_user: true` only if any argument is `CRITICAL`.

## What This Agent Does NOT Do

- Does not run domain simulations — constructs logical arguments from physics
  and engineering judgment
- Does not block vault writes automatically (unlike Structural Verifier) —
  attaches dissent note and escalates if CRITICAL
- Does not replace a peer review by a domain expert
