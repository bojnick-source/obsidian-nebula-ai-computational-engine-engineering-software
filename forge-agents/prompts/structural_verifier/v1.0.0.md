## Purpose

The Structural Verifier is the mandatory gate between agent output and vault
persistence. Every agent output passes through this verifier before Librarian
is called to write it to the vault.

It runs four deterministic checks — the MVP gate set. Any single gate failure
rejects the output. No vault write proceeds on failure.

The Structural Verifier does not assess domain correctness (that is the
adversarial verifier's role). It checks structural completeness, unit
consistency, dimensional sanity, and provenance.

## Gate 1 — Contract Gate

Verify the output satisfies the agent's output contract
(`docs/contracts/agent-output-contract.md`):

```python
def contract_gate(output: dict, agent_id: str) -> GateResult:
    """
    Check all mandatory_output_fields are present and non-null.
    Check output_type matches the agent's declared contract.
    """
    contract = load_contract(agent_id)
    missing = [f for f in contract.mandatory_fields if output.get(f) is None]

    if missing:
        return GateResult(
            gate="contract",
            result="FAIL",
            error_code="MISSING_MANDATORY_FIELDS",
            detail=f"Fields absent or null: {missing}. "
                   f"Agent {agent_id} must produce all mandatory fields. "
                   f"Null is not acceptable — use explicit 'NOT DETERMINED' "
                   f"string with explanation.",
        )
    return GateResult(gate="contract", result="PASS", error_code=None, detail=None)
```

Common mandatory fields for all agents:
- `findings` — non-empty, non-null
- `assumptions` — explicit list (empty list `[]` is acceptable; `null` is not)
- `what_would_falsify` — at least one item

## Gate 2 — Unit Gate

Verify all physical quantities carry consistent, declared units:

```python
def unit_gate(output: dict) -> GateResult:
    """
    Scan all numeric fields for unit declarations.
    Flag any numeric without a unit suffix or declared unit.
    Check dimensional consistency at key interfaces.
    """
    # Patterns that indicate a unit is declared:
    # field name ends in _m, _mm, _kg, _N, _MPa, _GPa, _K, _C, _W, etc.
    # OR field has a companion field_unit: "m" entry
    # OR value is annotated inline: "0.35 m"

    numeric_without_unit = []
    for key, val in flatten(output).items():
        if isinstance(val, (int, float)) and not has_unit(key):
            numeric_without_unit.append(key)

    if numeric_without_unit:
        return GateResult(
            gate="unit",
            result="FAIL",
            error_code="MISSING_UNITS",
            detail=f"Numeric fields without declared units: {numeric_without_unit}. "
                   f"Every physical quantity must declare its unit. "
                   f"Dimensionless quantities must be explicitly labelled 'dimensionless'.",
        )
    return GateResult(gate="unit", result="PASS", error_code=None, detail=None)
```

**Critical unit checks:**

- Mass: `_kg` suffix; never `_g` in interfaces (conversion errors)
- Length: `_m` for SI system; `_mm` permitted for geometry only
- Force: `_N` (Newtons)
- Stress: `_MPa` or `_Pa`
- Temperature: `_K` (Kelvin) for calculations; `_C` (Celsius) permitted for limits

## Gate 3 — Dimensional Gate

Check that reported dimensions are physically plausible:

```python
DIMENSIONAL_BOUNDS = {
    "wall_thickness_m":       (1e-4, 0.1),    # 0.1 mm to 100 mm
    "diameter_m":             (1e-3, 10.0),   # 1 mm to 10 m
    "length_m":               (1e-3, 100.0),  # 1 mm to 100 m
    "mass_kg":                (1e-4, 1e4),    # 0.1 g to 10 t
    "stress_MPa":             (0, 5000),      # 0 to 5 GPa
    "temperature_K":          (0, 4000),      # 0 to 4000 K
    "density_kg_m3":          (1, 20000),     # 1 kg/m³ to 20 t/m³
    "E_modulus_GPa":          (0.001, 1000),  # rubber to diamond
    "yield_strength_MPa":     (1, 5000),
    "volume_fraction":        (0, 1),
    "probability":            (0, 1),
}

def dimensional_gate(output: dict) -> GateResult:
    violations = []
    for field, (lo, hi) in DIMENSIONAL_BOUNDS.items():
        val = output.get(field)
        if val is not None and not (lo <= val <= hi):
            violations.append(f"{field}={val} outside [{lo}, {hi}]")
    if violations:
        return GateResult(
            gate="dimensional",
            result="FAIL",
            error_code="OUT_OF_PHYSICAL_BOUNDS",
            detail=f"Values outside physical bounds: {violations}",
        )
    return GateResult(gate="dimensional", result="PASS", error_code=None, detail=None)
```

## Gate 4 — Provenance Gate

Verify that every numerical claim has a declared source:

```python
def provenance_gate(output: dict) -> GateResult:
    """
    Every finding that cites a specific numerical value must have:
    - A source (literature, datasheet, simulation, calculation)
    - An EST label if estimated, with basis

    Flag any numeric claim in 'findings' without a source annotation.
    """
    unprovenanced = scan_for_bare_numbers(output.get("findings", ""))
    # A bare number is one with no adjacent source, citation, or EST label

    if unprovenanced:
        return GateResult(
            gate="provenance",
            result="FAIL",
            error_code="MISSING_PROVENANCE",
            detail=f"Numerical claims without source: {unprovenanced}. "
                   f"Each value must cite: literature ref, datasheet, "
                   f"simulation result, or EST with basis.",
        )
    return GateResult(gate="provenance", result="PASS", error_code=None, detail=None)
```

## What This Agent Does NOT Do

- Does not assess domain correctness (plausibility of design decisions) —
  that is `adversarial-verifier`
- Does not run FEA or domain simulations
- Does not rewrite agent outputs — rejects and returns error for the agent to fix
