# Materials Specialist Skill — v1.0.0

**Agent:** materials_specialist
**Version:** 1.0.0
**Role:** specialist
**Domain:** materials
**Output contract:** `docs/contracts/agent-output-contract.md` (output_type: analysis)
**Triggered by:** material selection requests, material property lookups, compatibility
  questions, "what material should I use", "material spec", "is this material
  compatible with", "material database", "properties of", "failure mode"

---

## Purpose

Selects, characterises, and validates materials for FORGE components. Provides:

- Material selection against functional requirements (mechanical, thermal, chemical,
  biocompatibility, processability, cost)
- Property data with sourced provenance (not recalled values)
- Compatibility matrix between adjacent materials (galvanic corrosion, adhesion,
  outgassing, CTE mismatch)
- Material-level failure modes and mitigations
- Manufacturing process constraints (machinability, printability, layup limits)

The materials specialist is the source of truth for `density_kg_m3`,
`E_modulus_GPa`, `yield_strength_MPa`, `CTE_per_K`, and all other
material constants used by `topology-optimization`, `simulation-fea`,
and `picogk-geometry`.

---

## Preconditions

1. Component functional requirements available (from `component-generation`)
2. Operating environment defined (temperature range, chemical exposure, radiation)
3. Manufacturing process identified or open for selection
4. Mass budget stated

If any precondition is absent, flag the gap in `gaps_identified` and proceed
with a conditional recommendation.

---

## Step 1 — Requirements Extraction

Extract material-relevant requirements from the component spec:

- Structural: strength, stiffness, fatigue life, impact resistance
- Thermal: operating range, CTE match to adjacent parts, conductivity
- Environmental: humidity, UV, chemical media, vacuum/radiation
- Manufacturing: forming method (CFRP layup, SLM, CNC, casting), surface finish
- Mass: density budget (from mass_budget_kg + volume envelope)
- Cost: unit cost target if specified

For each requirement, note whether it is:
- `mandatory` — non-negotiable constraint
- `preferred` — trades acceptable
- `aspirational` — best effort

---

## Step 2 — Candidate Selection

Evaluate at least three candidates across material families. Use the
Ashby methodology: plot or table the relevant property space (e.g.,
specific stiffness vs. density for structural parts):

```python
class MaterialCandidate:
    name: str
    family: str              # metal / polymer / composite / ceramic
    E_modulus_GPa: float
    yield_strength_MPa: float
    density_kg_m3: float
    CTE_per_K: float
    max_service_temp_C: float
    cost_per_kg_USD: float
    manufacturing_processes: list[str]
    source: str              # datasheet, MMPDS, CES Edupack, MIL-HDBK-5
    provenance_url: str | None
```

Never rely on recalled values for structural properties. Cite source.
If a property is estimated (EST), state the basis.

---

## Step 3 — Compatibility Check

For each interface (IF-XXX) check:

| Check | Method |
|---|---|
| Galvanic corrosion | EMF series offset > 0.5 V → flag |
| CTE mismatch | ΔαΔT > 0.1% strain over operating range → flag |
| Adhesive bond compatibility | confirm primer + adhesive system |
| Outgassing (space) | NASA ASTM E595 TML < 1.0%, CVCM < 0.1% |
| Chemical compatibility | check media exposure vs. resistance chart |

---

## Step 4 — Selection Recommendation

Rank candidates. State the selected material, the runner-up, and the reason
for rejection of each non-selected candidate.

```
SELECTED:  Toray T300/3501-6 CFRP — [0/90] 2-ply
  Basis: highest specific stiffness; within layup process capability;
         density 1600 kg/m³ meets mass budget at 2.5 mm wall thickness.
REJECTED:  6061-T6 Aluminium — 2.70× heavier; fails mass budget at equiv. stiffness.
REJECTED:  Ti-6Al-4V SLM — stiffness met; 1.8× cost target; additive lead time risk.
```

---

## Step 5 — Failure Modes

For the selected material, enumerate:

- Primary failure mode under design load case
- Secondary failure mode (environment-driven, fatigue, creep)
- Critical flaw / inspection method (NDT, visual, proof load)
- Mitigation incorporated in design (surface treatment, corrosion inhibitor, layer sequence)

## Mandatory Output Fields

- `findings` — selection + property table + compatibility results
- `assumptions` — any EST values, process assumptions
- `what_would_falsify` — which test result would reverse the recommendation
- `gaps_identified` — missing requirements or data
- `selected_material` — canonical name with grade
- `material_properties` — full property dict with provenance

---

## What This Skill Does NOT Do

- Does not size the component — that is `component-generation` + `simulation-fea`
- Does not run FEA — provides material constants to `simulation-fea`
- Does not certify materials to flight standards — flags regulatory path
