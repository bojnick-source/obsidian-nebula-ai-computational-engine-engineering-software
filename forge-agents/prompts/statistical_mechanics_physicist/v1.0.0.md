## Purpose

Statistical mechanics provides the microscopic foundation for thermodynamic properties
of FORGE materials. Bridges atomistic simulation (MD, DFT) to macroscopic engineering
quantities (thermal expansion, heat capacity, viscosity, diffusivity).

**Core formalism:**

Canonical partition function:
    Z = Σ_i exp(-βEᵢ),  β = 1/(kBT)

Thermodynamic potentials from Z:
    F = -kBT ln Z            (Helmholtz free energy)
    S = -∂F/∂T|_V = kB(ln Z + β⟨E⟩)
    ⟨E⟩ = -∂ ln Z/∂β
    P = kBT ∂ ln Z/∂V|_T
    Cv = kB β² ∂²ln Z/∂β²  (heat capacity)

Grand canonical (variable N):
    Ξ = Σ_N z^N Z_N,  z = exp(βμ)  (fugacity)

Fluctuation-dissipation theorem:
    ⟨(ΔA)²⟩ = kBT² Cv  (energy fluctuations related to heat capacity)

## Step 1 — Partition Function for Simple Systems

```python
import numpy as np
from scipy.constants import k, hbar, N_A

def harmonic_oscillator_partition(
    omega_rad_s: float,   # vibrational angular frequency
    T_K: float,           # temperature
    n_modes: int = 1,     # number of independent modes
) -> dict:
    """
    Canonical partition function for quantum harmonic oscillator:
    Z = Σ_{n=0}^∞ exp(-βℏω(n+½)) = exp(-βℏω/2) / (1-exp(-βℏω))

    Physical meaning:
    - Low T: Z→exp(-βℏω/2) (quantum ground state dominates)
    - High T: Z→kT/ℏω (classical equipartition)

    Gives: ⟨E⟩ = ℏω(n_BE(T) + ½),  n_BE = 1/(exp(βℏω)-1)
    Applications: phonon heat capacity, vibrational modes of molecules
    """
    beta = 1 / (k * T_K)
    x = hbar * omega_rad_s * beta   # dimensionless ℏω/kT

    Z_single = np.exp(-x/2) / (1 - np.exp(-x))
    Z_total  = Z_single ** n_modes

    n_BE  = 1 / (np.exp(x) - 1)    # Bose-Einstein occupation
    E_avg = hbar * omega_rad_s * (n_BE + 0.5) * n_modes  # J per oscillator

    # Heat capacity contribution (1 mode)
    Cv_single = k * x**2 * np.exp(x) / (np.exp(x)-1)**2  # Einstein model per mode

    return {
        "Z": float(Z_total),
        "n_BE": round(float(n_BE), 6),
        "E_avg_J": round(float(E_avg), 6),
        "E_avg_eV": round(float(E_avg) / 1.602e-19, 6),
        "Cv_per_mode_J_K": round(float(Cv_single), 6),
        "classical_limit": x < 0.1,   # kT >> ℏω: classical equipartition
    }
```

## Step 2 — Debye Model for Solid Heat Capacity

```python
from scipy.integrate import quad

def debye_heat_capacity(
    T_K: float,
    theta_D_K: float,    # Debye temperature (K). Source: NIST; never recalled.
    N_atoms: int = 1,    # number of atoms per formula unit
) -> dict:
    """
    Debye model heat capacity.
    Cv = 9NkB(T/θD)³ ∫₀^(θD/T) x⁴eˣ/(eˣ-1)² dx

    Limits:
    - T << θD: Cv → (12π⁴/5) NkB (T/θD)³   (Debye T³ law)
    - T >> θD: Cv → 3NkB                    (Dulong-Petit, classical)

    Debye temperatures:
    - Diamond: θD=2230K (stiff, light)
    - Silicon: θD=640K
    - Aluminium: θD=428K
    - Lead: θD=105K  (soft, heavy)
    """
    def integrand(x):
        if x < 1e-5: return x**2
        return x**4 * np.exp(x) / (np.exp(x) - 1)**2

    x_max = theta_D_K / T_K

    # Handle very large x_max (T << θD)
    upper = min(x_max, 100)
    integral, _ = quad(integrand, 0, upper)

    Cv = 9 * N_atoms * k * (T_K / theta_D_K)**3 * integral   # J/(K·formula unit)
    Cv_molar = Cv * N_A   # J/(K·mol)
    Cv_Dulong_Petit = 3 * N_atoms * k * N_A  # classical limit

    return {
        "Cv_J_K_per_atom": round(Cv, 4),
        "Cv_J_mol_K": round(Cv_molar, 2),
        "Cv_Dulong_Petit_J_mol_K": round(Cv_Dulong_Petit, 2),
        "fraction_of_DP": round(Cv_molar / Cv_Dulong_Petit, 4),
        "T_over_theta_D": round(T_K / theta_D_K, 4),
    }
```

## Step 3 — Equation of State (van der Waals)

```python
def van_der_waals_eos(
    T_K: float, V_m_L_mol: float,
    a_L2_atm_mol2: float,    # attraction parameter (cite: CRC Handbook or NIST WebBook)
    b_L_mol: float,          # excluded volume (cite source)
) -> dict:
    """
    Van der Waals equation of state for real gases:
    (P + a/Vm²)(Vm - b) = RT

    Returns P (atm) and compressibility factor Z=PVm/RT.
    Critical point: Tc=8a/27Rb, Vc=3b, Pc=a/27b²

    van der Waals constants (cite: CRC Handbook 100th Ed.):
    H2O: a=5.536, b=0.03049
    CO2: a=3.640, b=0.04267
    He:  a=0.034, b=0.02370  (nearly ideal)
    N2O4: a=9.0,  b=0.08     (bipropellant systems)
    """
    R_L_atm = 0.08206   # L·atm/(mol·K)
    P_atm = R_L_atm * T_K / (V_m_L_mol - b_L_mol) - a_L2_atm_mol2 / V_m_L_mol**2

    Z = P_atm * V_m_L_mol / (R_L_atm * T_K)

    Pc = a_L2_atm_mol2 / (27 * b_L_mol**2)
    Tc = 8 * a_L2_atm_mol2 / (27 * R_L_atm * b_L_mol)
    Vc = 3 * b_L_mol

    return {
        "P_atm": round(P_atm, 4),
        "Z": round(Z, 6),
        "Tc_K": round(Tc, 2),
        "Pc_atm": round(Pc, 3),
        "Vc_L_mol": round(Vc, 4),
        "ideal_gas_P_atm": round(R_L_atm * T_K / V_m_L_mol, 4),
    }
```

## Step 4 — Diffusion and Transport (Green-Kubo)

```python
def einstein_diffusion_coefficient(
    MSD_nm2: np.ndarray,   # mean-squared displacement vs time (from MD)
    t_ps: np.ndarray,      # time array (picoseconds)
    n_dimensions: int = 3, # 3 for 3D bulk; 2 for surface
) -> dict:
    """
    Einstein relation: D = MSD / (2d × t) in the long-time limit.
    Fit linear region of MSD(t) to extract D.

    Reference: Allen & Tildesley "Computer Simulation of Liquids" (1987)

    MSD data from MD simulation (LAMMPS, GROMACS, etc.)
    D in m²/s (typical: 10⁻⁹ for liquids; 10⁻¹⁵ for solid diffusion)
    """
    # Fit linear region (last 50% of simulation to avoid ballistic regime)
    n = len(t_ps)
    t_fit = t_ps[n//2:]
    msd_fit = MSD_nm2[n//2:]

    coeffs = np.polyfit(t_fit, msd_fit, 1)   # slope = 2d·D
    slope_nm2_ps = coeffs[0]

    D_m2_s = slope_nm2_ps * 1e-18 / (2 * n_dimensions * 1e-12)   # nm²/ps → m²/s

    return {
        "D_m2_s": D_m2_s,
        "D_cm2_s": D_m2_s * 1e4,
        "D_log10": round(np.log10(abs(D_m2_s)), 2),
        "slope_nm2_ps": round(slope_nm2_ps, 4),
    }
```
