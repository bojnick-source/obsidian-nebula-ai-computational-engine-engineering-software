## Purpose

Provides PDE formulation, discretisation, and numerical analysis guidance for
FORGE agents running physics simulations. Consumed by:

- `simulation-fea` — weak form, element formulation, convergence
- `topology-optimization` — adjoint sensitivity, filter PDE
- `thermal-fluids-specialist` — CFD formulation, stability criteria
- `plasma-specialist` — plasma fluid equations, MHD

Responsibilities:

- Classify the PDE (elliptic / parabolic / hyperbolic) and its well-posedness
- Derive the weak form (Galerkin / Petrov-Galerkin)
- Select discretisation method (FEM, FVM, FDM) and justify
- State stability and consistency conditions (CFL, inf-sup, coercivity)
- Verify mesh convergence order
- Identify boundary condition issues (Dirichlet, Neumann, Robin, interface)

## Step 1 — PDE Classification and Well-Posedness

Classify the PDE for a scalar equation Au = f:

```
Elliptic:   Δu = f               → Laplace / Poisson; boundary value problem
Parabolic:  ∂u/∂t = α∇²u        → Heat equation; initial + boundary conditions
Hyperbolic: ∂²u/∂t² = c²∇²u     → Wave equation; initial + boundary conditions
```

For a system (e.g., linear elasticity, Navier-Stokes):

- Identify characteristic structure
- State existence and uniqueness conditions
- Identify potential ill-posedness (e.g., incompressibility constraint in Stokes)

---

## Step 2 — Weak Formulation

Derive the weak form by multiplying by a test function v ∈ V and integrating:

```
Strong form (linear elasticity):
  -∇·σ = f  in Ω
   σ = C : ε(u)
   u = u_D  on Γ_D   (Dirichlet)
   σ·n = t  on Γ_N   (Neumann)

Weak form:
  Find u ∈ H¹(Ω) such that for all v ∈ H¹_0(Ω):
  ∫_Ω ε(v) : C : ε(u) dΩ = ∫_Ω v·f dΩ + ∫_Γ_N v·t dΓ

Bilinear form: a(u,v) = ∫_Ω ε(v) : C : ε(u) dΩ
Linear functional: l(v) = ∫_Ω v·f dΩ + ∫_Γ_N v·t dΓ
```

State coercivity and continuity constants for the Lax-Milgram theorem.

## Step 3 — Discretisation

For FEM — specify:

```python
class FEMDiscretisation:
    element_type: str      # "Q1" | "Q2" | "P1" | "P2" | "Hermite" | "MINI"
    order: int             # polynomial order p
    n_elements: int        # N_el
    n_dof: int             # degrees of freedom
    integration_rule: str  # "Gauss-Legendre" | "reduced" | "full"
    n_gauss_points: int    # per element

    # Convergence rate (smooth solution):
    # ||u - u_h||_H1 ≤ C × h^p × |u|_H(p+1)
    # ||u - u_h||_L2 ≤ C × h^(p+1)
```

State expected convergence rate for the chosen element and solution regularity.

For mixed elements (e.g., Stokes u/p): state inf-sup stability condition
and compatible element pairs (Taylor-Hood P2/P1 ✅; equal-order P1/P1 ✗
without stabilisation).

---

## Step 4 — Stability Conditions

**For time-dependent problems:**

```
CFL condition (explicit time-stepping):
  Δt ≤ CFL × h / c_max
  CFL = 1.0 (1D), CFL_safe ≈ 0.5 (multidim, safety factor)

Diffusion stability (explicit):
  Δt ≤ h² / (2α)   where α = k/(ρ c_p) is thermal diffusivity
```

For implicit methods: state unconditional stability and the algebraic
system that must be solved per time step.

**For eigenvalue problems:**
State spectral radius condition and recommended solver (Lanczos, ARPACK).

## Step 5 — Mesh Convergence Study

Prescribe a convergence study protocol:

```python
def convergence_study(solver_fn, mesh_sizes, reference_solution=None):
    """
    Run solver at multiple mesh sizes h and compute:
      - L2 error vs. reference (or Richardson extrapolation)
      - H1 seminorm error
      - Convergence rate p = log(e1/e2) / log(h1/h2)
    """
    errors_L2 = []
    errors_H1 = []
    for h in mesh_sizes:
        u_h = solver_fn(h)
        if reference_solution is not None:
            e_L2 = compute_L2_error(u_h, reference_solution)
            e_H1 = compute_H1_error(u_h, reference_solution)
        else:
            # Richardson extrapolation using two finest meshes
            pass
        errors_L2.append(e_L2)
        errors_H1.append(e_H1)
    return errors_L2, errors_H1
```

Target: achieve convergence rate within 10% of theoretical for at least
3 consecutive mesh refinements.
