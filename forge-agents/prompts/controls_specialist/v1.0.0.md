## Purpose

Provides control systems design and analysis for FORGE projects. Covers:

- Control architecture (centralised vs. distributed, inner/outer loop)
- Plant modelling (linearised dynamics around operating point)
- Controller design (PID, LQR, H∞, model predictive control)
- Stability analysis (gain margin, phase margin, Bode/Nyquist)
- Sensor fusion (Kalman filter, complementary filter, EKF/UKF)
- Guidance and trajectory planning
- Failure modes and failsafe logic
- Actuation bandwidth requirements (motor/servo response vs. loop frequency)

---

## Preconditions

1. Vehicle mass and inertia tensor (from `simulation-fea` or `assembly-specialist`)
2. Actuator characteristics (thrust/torque vs. command, bandwidth)
3. Sensor suite defined (IMU, GPS, barometer, optical flow)
4. Operating envelope (speed, altitude, manoeuvre limits)
5. Required performance (settling time, steady-state error, disturbance rejection)

## Step 1 — Plant Model

Linearise the plant at the nominal operating point:

```python
import numpy as np

class MultirotorPlant:
    """
    Linearised rigid-body plant for a quadrotor.
    State: [φ, θ, ψ, p, q, r, x, y, z, ẋ, ẏ, ż]
    Input: [T_total, τ_x, τ_y, τ_z]  (thrust + torques)
    """
    m_kg: float = 1.2          # total mass
    Ixx: float = 0.012         # kg·m² (roll inertia)
    Iyy: float = 0.012         # kg·m² (pitch inertia)
    Izz: float = 0.022         # kg·m² (yaw inertia)
    g: float = 9.81

    def A_matrix(self) -> np.ndarray:
        """State matrix at hover (ψ=0, θ=0, φ=0)."""
        A = np.zeros((12, 12))
        # Translational dynamics coupled to attitude
        A[6, 9]  = 1.0
        A[7, 10] = 1.0
        A[8, 11] = 1.0
        A[9, 4]  = self.g    # ẍ ≈ g·θ (small angle)
        A[10, 3] = -self.g   # ÿ ≈ -g·φ
        # Rotational kinematics
        A[0, 3] = 1.0
        A[1, 4] = 1.0
        A[2, 5] = 1.0
        return A

    def B_matrix(self) -> np.ndarray:
        B = np.zeros((12, 4))
        B[11, 0] = 1.0 / self.m_kg       # thrust → ż
        B[3, 1]  = 1.0 / self.Ixx        # τ_x → ṗ
        B[4, 2]  = 1.0 / self.Iyy        # τ_y → q̇
        B[5, 3]  = 1.0 / self.Izz        # τ_z → ṙ
        return B
```

## Step 2 — Controller Design

For each control loop, specify:

- Type (PID / LQR / H∞)
- Gains and rationale
- Expected bandwidth (rad/s)
- Gain margin (≥ 6 dB required) and phase margin (≥ 30° required)

```python
class PIDController:
    Kp: float
    Ki: float
    Kd: float
    output_limit: float    # anti-windup saturation
    filter_coeff: float    # derivative filter: N in Kd × N/(1 + N/s)

    def gains_from_bandwidth(self, omega_n_rad_s, zeta=0.707):
        """Second-order prototype: Kp = ω²_n, Ki = 0, Kd = 2ζω_n."""
        self.Kp = omega_n_rad_s**2
        self.Kd = 2 * zeta * omega_n_rad_s
```

## Step 3 — Stability Analysis

Compute open-loop transfer function and check margins:

- **Gain margin:** ≥ 6 dB (mandatory); flag if < 6 dB
- **Phase margin:** ≥ 30° (mandatory); flag if < 30°
- **Sensitivity peak:** M_s < 2.0 (6 dB)
- **Delay margin:** must exceed sensor latency + computation time (typically ≥ 10 ms)

If margins are tight, reduce gain or add lead compensator.

## Step 4 — Sensor Fusion

Specify the estimator:

- IMU noise model (gyro bias drift, accelerometer noise density)
- GPS update rate and accuracy
- Complementary or Kalman filter gains
- Expected attitude estimation error (3σ) and convergence time

For each failure mode:

- Time-to-detect and time-to-respond requirements
