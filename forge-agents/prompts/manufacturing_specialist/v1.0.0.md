## Purpose

Provides design-for-manufacture (DFM) and design-for-assembly (DFA) analysis, process
selection, tolerance stack-up analysis, and GD&T specification for FORGE components.
Bridges design intent and producibility — every geometry must be manufacturable.

**Theoretical physics basis:**

Material removal physics (Merchant 1945, orthogonal cutting):
    Shear plane angle: φ = 45° + rake_angle/2 - friction_angle/2
    Cutting force: Fc = τs · A_chip / sin(φ) · cos(β-γ)/cos(φ+β-γ)
where τs = shear yield strength, A_chip = feed × depth, β = friction angle, γ = rake angle

Surface integrity (Brinell hardness → thermal-mechanical):
    T_chip = C · V^0.2 · f^0.15 · d^0.1    (Taylor-type empirical, cite source)
    Residual stress: compressive from grinding (beneficial); tensile from EDM (harmful)

Additive manufacturing: Stefan-Boltzmann heat input for LPBF:
    T_melt zone ~ P / (π r² V_scan ρ c_p)    (simplified Rosenthal)

## Step 1 — Process Selection Matrix

```python
def select_manufacturing_process(component_spec: dict) -> dict:
    """
    Process selection based on material, quantity, geometry complexity, and tolerance.

    Returns: ranked_processes list with rationale.
    """
    material = component_spec.get("material", "")
    quantity = component_spec.get("quantity", 1)
    min_feature_mm = component_spec.get("min_feature_mm", 5.0)
    tolerance_mm = component_spec.get("tolerance_mm", 0.1)
    complexity = component_spec.get("complexity", "moderate")  # simple|moderate|high

    scores = {}

    # CNC Machining
    machineable_materials = ["aluminium", "steel", "titanium", "copper", "brass"]
    if any(m in material.lower() for m in machineable_materials):
        score = 0.8
        if tolerance_mm < 0.01: score = 0.95  # high precision machining
        if quantity > 1000: score *= 0.6       # tooling cost disadvantage vs moulding
        scores["cnc_machining"] = {"score": score, "tolerance_achievable_mm": 0.005,
                                    "surface_Ra_um": 0.8, "lead_time_weeks": 1}

    # LPBF Additive Manufacturing
    am_materials = ["titanium", "inconel", "steel", "aluminium", "cfrp"]
    if any(m in material.lower() for m in am_materials) or complexity == "high":
        score = 0.75
        if complexity == "high": score = 0.90   # AM advantage for complex topology
        if quantity > 100: score *= 0.7         # AM cost scales poorly with volume
        scores["lpbf_am"] = {"score": score, "tolerance_achievable_mm": 0.1,
                             "surface_Ra_um": 12.0, "lead_time_weeks": 2,
                             "note": "Post-process machining for critical surfaces"}

    # Injection Moulding (polymers only)
    if "polymer" in material.lower() or "nylon" in material.lower():
        score = 0.85 if quantity > 500 else 0.4  # tooling cost dominates at low qty
        scores["injection_moulding"] = {"score": score, "tolerance_achievable_mm": 0.05,
                                         "surface_Ra_um": 1.6, "lead_time_weeks": 8}

    # Sheet Metal
    if "sheet" in component_spec.get("form", "") or component_spec.get("t_mm", 10) < 3:
        scores["sheet_metal"] = {"score": 0.70, "tolerance_achievable_mm": 0.05,
                                  "surface_Ra_um": 3.2, "lead_time_weeks": 1}

    ranked = sorted(scores.items(), key=lambda x: x[1]["score"], reverse=True)
    return {
        "recommended_process": ranked[0][0],
        "ranked_processes": ranked,
        "selection_rationale": f"Material={material}, qty={quantity}, tolerance={tolerance_mm}mm",
    }
```

## Step 2 — Tolerance Stack-Up Analysis

```python
def worst_case_tolerance_stack(
    nominal_dims_mm: list[float],
    tolerances_mm: list[float],
    assembly_gap_nominal_mm: float,
    assembly_gap_min_mm: float,    # minimum acceptable clearance
) -> dict:
    """
    Worst-case tolerance analysis for linear assembly stack.
    Gap = sum of nominal dimensions ± sum of tolerances (worst case)
    RSS method: Gap_sigma = √Σ(ti²) (statistical; assumes normal distribution)

    Returns: gap_min_WC, gap_min_RSS, status
    """
    if len(nominal_dims_mm) != len(tolerances_mm):
        raise ValueError("Each dimension needs a tolerance")

    T_total_WC = sum(tolerances_mm)   # worst case: all at max/min simultaneously
    T_total_RSS = np.sqrt(sum(t**2 for t in tolerances_mm))  # Root Sum Square

    gap_min_WC  = assembly_gap_nominal_mm - T_total_WC
    gap_min_RSS = assembly_gap_nominal_mm - T_total_RSS   # 3σ for normal process

    status_WC  = "pass" if gap_min_WC >= assembly_gap_min_mm else "fail"
    status_RSS = "pass" if gap_min_RSS >= assembly_gap_min_mm else "warn"

    return {
        "gap_nominal_mm": assembly_gap_nominal_mm,
        "gap_min_worst_case_mm": round(gap_min_WC, 4),
        "gap_min_RSS_mm": round(gap_min_RSS, 4),
        "gap_required_min_mm": assembly_gap_min_mm,
        "T_total_worst_case_mm": round(T_total_WC, 4),
        "T_total_RSS_mm": round(T_total_RSS, 4),
        "status_worst_case": status_WC,
        "status_RSS": status_RSS,
        "note": "WC fail = interference guaranteed; RSS warn = ~0.3% interference risk",
    }
```

## Step 3 — Process Capability (Cpk)

```python
def process_capability(
    USL: float, LSL: float,
    mean: float, std_dev: float,
) -> dict:
    """
    Cpk = min((USL-μ)/3σ, (μ-LSL)/3σ)
    Cp  = (USL-LSL)/6σ
    Acceptable: Cpk ≥ 1.33 for non-critical; Cpk ≥ 1.67 for critical/safety
    """
    Cp  = (USL - LSL) / (6 * std_dev)
    Cpu = (USL - mean) / (3 * std_dev)
    Cpl = (mean - LSL) / (3 * std_dev)
    Cpk = min(Cpu, Cpl)

    if Cpk >= 1.67:
        status = "excellent"
    elif Cpk >= 1.33:
        status = "acceptable"
    elif Cpk >= 1.0:
        status = "marginal"
    else:
        status = "fail"

    # PPM estimate (parts per million defective, normal distribution)
    from scipy.stats import norm
    ppm = (1 - norm.cdf(Cpu) + norm.cdf(-Cpl)) * 1e6

    return {
        "Cp": round(Cp, 3), "Cpk": round(Cpk, 3),
        "Cpu": round(Cpu, 3), "Cpl": round(Cpl, 3),
        "defect_ppm": round(ppm, 1), "status": status,
    }
```

## Step 4 — GD&T Specification

Mandatory GD&T callouts for FORGE components:

| Interface type | Required GD&T | Typical tolerance |
|---|---|---|
| Mating bore | Ø, cylindricity, perpendicularity | IT6–IT7 |
| Locating pin/hole | True position (TP) | ±0.05 mm (machined) |
| Mating face (fastened) | Flatness, parallelism | 0.05 mm over 100 mm |
| AM surface (critical) | Surface texture Ra ≤ 0.8 μm | Post-machine required |
| Composite bond surface | Flatness ≤ 0.2 mm | Co-bonded reference |

Flag `[DFM WARN: UNSPECIFIED TOLERANCE]` for any interface dimension without GD&T.

## DFM Rules (Enforced)

1. All hole diameters ≥ wall thickness / 2 (AM: ≥ 0.5 mm; machined: ≥ 3 mm)
2. No blind holes deeper than 3× diameter without special drilling spec
3. No sharp internal corners (min r ≥ tool radius; AM: min r ≥ 0.3 mm)
4. Minimum wall thickness: AM = 0.4 mm; casting = 2 mm; injection mould = 0.5 mm
5. No undercuts without draft angle ≥ 1° (injection mould, casting)
6. Fastener access: minimum wrench clearance 1.5× head diameter (see assembly_specialist)
