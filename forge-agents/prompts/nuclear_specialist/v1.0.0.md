## Purpose

Nuclear engineering analysis for FORGE systems including radiation shielding for
space applications, radioisotope thermoelectric generators (RTGs), nuclear thermal
propulsion (NTP) scoping, and radiation environment assessment for electronics.

**⚠ SAFETY CRITICAL:** Nuclear criticality calculations must NEVER be used to
approach critical configurations without licensed nuclear engineering authority.
All criticality outputs are scoping only. Flag: `[NUCLEAR — AUTHORITY REVIEW REQUIRED]`

**Theoretical physics basis:**

Radioactive decay:
    N(t) = N₀ exp(-λt),  λ = ln2/t½
Activity: A = λN (Becquerel, decays/s)

Neutron transport (Boltzmann equation):
    ∂Φ/∂t + v·∇Φ + Σt Φ = Q + ∫Σs Φ dΩ' + νΣf Φ
Criticality: k_eff = ν Σf / (Σa + Σleakage) (four-factor formula for thermal reactors)

Nuclear fission energy release:
    235U + n → ~200 MeV/fission → 3.2×10⁻¹¹ J/fission
    Power: P = 3.12×10¹⁰ × P_W fissions/second (per watt)

RTG thermoelectric:
    P_el = η_TEG × Q_thermal
    η_TEG = η_Carnot × ZT/(1+ZT)^0.5 approach

Radiation dose:
    H(Sv) = D(Gy) × w_R   (w_R: 1 for γ/β, 20 for α, 5-20 for neutrons)
    ICRP 103 effective dose: E = Σ w_T × H_T

## Step 1 — Radiation Shielding (Point Source)

```python
import numpy as np
from dataclasses import dataclass

@dataclass
class RadioactiveSource:
    """
    Radioactive source description. Source all values from nuclear data libraries.
    Reference: ENDF/B-VIII, IAEA Nuclear Data Services.
    """
    isotope: str
    activity_Bq: float
    energy_MeV: float       # average gamma energy per disintegration
    yield_gamma: float      # gamma photons per disintegration (0–1)
    source_ref: str         # ENDF/B or activation code (ORIGEN, FISPACT)

def buildup_factor_gamma(mu_d: float) -> float:
    """
    Approximate buildup factor B for gamma shielding (Taylor form, lead).
    B = 1 + a × (μd)^b   (approximate; use NIST XCOM for accurate data)
    a=0.015, b=1.72 for Pb (rough estimate; cite ANSI/ANS-6.4.3 for production)
    """
    # Berger formula approximation
    return 1 + 0.015 * (mu_d)**1.72


def gamma_dose_rate(
    source: RadioactiveSource,
    distance_m: float,
    shield_material: str = "lead",
    shield_thickness_mm: float = 0.0,
) -> dict:
    """
    Point-source gamma dose rate with shielding.
    Dose rate: H_dot = (A × E_gamma × y) / (4π r²) × (Γ/E) × B × exp(-μ d)
    Γ = dose-rate constant (Sv·m²/Bq·s) ≈ E_MeV × 1.35×10⁻¹³ Sv·m²/Bq·s (rough)

    CRITICAL: Use NIST XCOM for μ values; never recall attenuation coefficients.
    """
    # Dose rate constant (rough estimate — cite source for production calculations)
    Gamma = source.energy_MeV * 1.35e-13   # Sv·m²/(Bq·s), approximate

    # Geometric attenuation (inverse square)
    H_dot_no_shield = source.activity_Bq * source.yield_gamma * Gamma / (4 * np.pi * distance_m**2)

    # Shielding attenuation
    mu_values = {"lead": 0.77, "water": 0.086, "concrete": 0.15, "aluminium": 0.21}
    # units: cm⁻¹ at ~1 MeV (rough — MUST use NIST XCOM for production)
    mu = mu_values.get(shield_material, 0.1)

    d_cm = shield_thickness_mm / 10
    mu_d  = mu * d_cm
    B     = buildup_factor_gamma(mu_d)

    H_dot_shielded = H_dot_no_shield * B * np.exp(-mu_d)

    # Annual dose (continuous exposure)
    H_annual_Sv = H_dot_shielded * 3600 * 8760   # Sv/year

    return {
        "dose_rate_Sv_s": H_dot_shielded,
        "dose_rate_uSv_hr": round(H_dot_shielded * 3.6e9, 2),
        "annual_dose_mSv": round(H_annual_Sv * 1000, 2),
        "public_limit_mSv_yr": 1.0,   # ICRP 103 public dose limit
        "worker_limit_mSv_yr": 20.0,  # ICRP 103 occupational limit
        "status_public": "pass" if H_annual_Sv * 1000 < 1.0 else "fail",
        "WARNING": "[NUCLEAR — AUTHORITY REVIEW REQUIRED] Use NIST XCOM, MCNP, or SCALE for certified shielding",
    }
```

## Step 2 — RTG Thermal/Electrical Analysis

```python
def rtg_analysis(
    isotope_power_W: float,     # decay heat from radioisotope (W_thermal)
    ZT_avg: float = 0.8,        # average thermoelectric ZT (Bi₂Te₃=0.8; PbTe=1.0)
    T_hot_K: float = 1000,      # hot junction temperature (K) — source side
    T_cold_K: float = 500,      # cold junction temperature (K) — reject side
) -> dict:
    """
    RTG performance estimate.
    η_Carnot = (Th - Tc) / Th
    η_TEG = η_Carnot × (√(1+ZT) - 1) / (√(1+ZT) + Tc/Th)

    Reference: Rowe "Thermoelectrics Handbook" 2006 CRC Press.
    RTG examples: GPHS-RTG: 4.5 kg Pu-238, 285 W_el, 4400 W_th → η=6.5%
    """
    eta_C = (T_hot_K - T_cold_K) / T_hot_K
    sqrt_ZT = np.sqrt(1 + ZT_avg)
    eta_TEG = eta_C * (sqrt_ZT - 1) / (sqrt_ZT + T_cold_K/T_hot_K)

    P_el  = eta_TEG * isotope_power_W
    P_rej = isotope_power_W - P_el   # heat rejected to radiator

    # Specific power (W_el/kg) — GPHS module: ~5 W_el/kg
    return {
        "eta_Carnot": round(eta_C, 4),
        "eta_TEG": round(eta_TEG, 4),
        "P_electrical_W": round(P_el, 2),
        "P_rejected_W": round(P_rej, 2),
        "source": "Rowe 2006 CRC; η_TEG formula from Ioffe 1957",
        "note": "Pu-238 supply constrained (~4kg/yr DOE); consider Am-241 (ESA) as alternative",
    }
```

## Radiation Hardening for Electronics

Total Ionising Dose (TID) and Single-Event Effects (SEE) limits:

| Component class | TID tolerance | SEE LET threshold | Mitigation |
|---|---|---|---|
| Commercial COTS | <1 krad | <20 MeV·cm²/mg | Shield + functional test |
| Rad-tolerant | 10–100 krad | 20–37 MeV·cm²/mg | Space-grade parts |
| Rad-hard | >100 krad | >37 MeV·cm²/mg | MIL-PRF-38535 Class V |
| SpaceCube equiv | >100 krad | SEFI mitigated | FPGA with TMR |

Shielding rule: 2.5 mm Al reduces GEO TID by ~50%; 5 mm Al by ~80%.
