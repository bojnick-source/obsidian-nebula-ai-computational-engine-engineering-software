## Purpose

Performs finite element analysis (FEA) on FORGE-generated geometry to validate
structural integrity under defined load cases. Primary solver: CalculiX (open-source,
ABAQUS input deck compatible). Secondary: FEniCS (Python, unstructured mesh). FEA
is the structural ground truth for FORGE — if FEA says it fails, it fails.

**Theoretical physics basis:** FEA discretizes the strong form of the linear momentum
balance equation into a weak (variational) form. The principle of virtual work:

    δW_int = δW_ext
    ∫_Ω σ:δε dV = ∫_Ω b·δu dV + ∫_∂Ω_N t·δu dA

Constitutive relation for linear elastic isotropic material:
    σ_ij = λ δ_ij ε_kk + 2μ ε_ij
where λ = Eν/[(1+ν)(1-2ν)], μ = E/[2(1+ν)] are Lamé parameters.

## Preconditions

1. **Geometry exported** — `.vdb`/`.stl` from picogk-geometry with `ready_for_fea: true`
2. **Load cases defined** — same load cases used in topology-optimization (magnitudes,
   directions, application points, all with units in N and Pa)
3. **Boundary conditions** — fixed DOFs, symmetry planes, contact definitions
4. **Material properties** — from materials-specialist with provenance (E, ν, ρ, σ_y)
5. **Mesh convergence target** — element size criterion stated (default: 3-level h-refinement)

Do not proceed if geometry is not watertight (checked via `meshfix` or `manifold2`).
Flag: `[FEA BLOCKED: GEOMETRY NOT WATERTIGHT]`

## Step 1 — Mesh Generation

Convert `.stl` to analysis-grade mesh using Gmsh (preferred) or Netgen:

```python
import gmsh
import subprocess
from pathlib import Path

def generate_mesh(stl_path: str, target_element_size_mm: float = 2.0) -> str:
    """
    Convert STL to .msh FEA mesh. Returns path to .msh file.

    Gmsh mesh strategy:
    - Surface: Frontal-Delaunay (algorithm 6)
    - Volume: Delaunay (algorithm 1)
    - Element order: 2nd-order tetrahedral (Tet10) for accuracy
    - Minimum element size: target_element_size_mm / 10
    - Maximum element size: target_element_size_mm

    Quality metrics to check:
    - Minimum scaled Jacobian > 0.1 (warn if < 0.2)
    - No inverted elements (Jacobian < 0)
    """
    gmsh.initialize()
    gmsh.model.add("fea_model")

    # Merge STL geometry
    gmsh.merge(stl_path)
    gmsh.model.mesh.classifySurfaces(angle=np.pi/4, boundary=True, forRho=True)
    gmsh.model.mesh.createGeometry()

    # Set element sizes
    gmsh.option.setNumber("Mesh.CharacteristicLengthMin", target_element_size_mm / 10)
    gmsh.option.setNumber("Mesh.CharacteristicLengthMax", target_element_size_mm)
    gmsh.option.setNumber("Mesh.Algorithm", 6)       # Frontal-Delaunay surface
    gmsh.option.setNumber("Mesh.Algorithm3D", 1)     # Delaunay volume
    gmsh.option.setNumber("Mesh.ElementOrder", 2)    # Tet10 quadratic elements

    gmsh.model.mesh.generate(3)

    msh_path = stl_path.replace(".stl", ".msh")
    gmsh.write(msh_path)
    gmsh.finalize()

    _check_mesh_quality(msh_path)
    return msh_path


def _check_mesh_quality(msh_path: str) -> None:
    """Check for inverted elements and low-quality elements."""
    result = subprocess.run(
        ["gmsh", msh_path, "-check"],
        capture_output=True, text=True
    )
    if "negative Jacobian" in result.stdout.lower():
        raise ValueError(
            f"[FEA BLOCKED: INVERTED ELEMENTS] Mesh {msh_path} has inverted "
            "elements. Increase element size or repair STL before meshing."
        )
```

**Mesh density guide:**

| Component type | Target element size | Min wall coverage |
|---|---|---|
| Thin shell (t < 3 mm) | t/3 | ≥ 3 elements through thickness |
| Structural frame | 2–5 mm | 4 elements min cross-section |
| Large casting | 5–10 mm | 3 elements min wall |
| AM lattice strut | d/4 | ≥ 3 elements per strut |

## Step 2 — CalculiX Input Deck

Generate `.inp` file for CalculiX (ABAQUS-format):

```python
def write_calculix_inp(
    mesh_path: str,
    material_E_MPa: float,
    material_nu: float,
    material_rho_kg_m3: float,
    load_cases: list[dict],
    fixed_node_sets: list[str],
    output_path: str,
) -> str:
    """
    Write a CalculiX .inp input deck for linear static analysis.

    load_cases example:
    [
        {"name": "LC1_cruise", "nodes": "TOP_SURFACE", "type": "PRESSURE",
         "magnitude_MPa": 0.05, "direction": None},
        {"name": "LC1_inertia", "nodes": "ALL", "type": "GRAVITY",
         "magnitude_m_s2": 9.81, "direction": [0, 0, -1]},
    ]

    Returns path to .inp file.
    """
    with open(output_path, "w") as f:
        # Mesh inclusion
        f.write(f"*INCLUDE, INPUT={mesh_path}\n\n")

        # Material definition
        f.write("*MATERIAL, NAME=STRUCT_MATERIAL\n")
        f.write("*ELASTIC\n")
        f.write(f"{material_E_MPa:.1f}, {material_nu:.4f}\n")
        f.write("*DENSITY\n")
        f.write(f"{material_rho_kg_m3 * 1e-12:.6e}\n\n")  # kg/m3 → t/mm3 for MPa system

        # Section
        f.write("*SOLID SECTION, ELSET=EALL, MATERIAL=STRUCT_MATERIAL\n\n")

        # Static step
        f.write("*STEP, NLGEOM=NO\n")
        f.write("*STATIC\n\n")

        # Boundary conditions (fixed)
        for node_set in fixed_node_sets:
            f.write(f"*BOUNDARY\n{node_set}, 1, 6\n\n")

        # Loads
        for lc in load_cases:
            if lc["type"] == "PRESSURE":
                f.write(f"*DLOAD\n{lc['nodes']}, P, {lc['magnitude_MPa']:.6f}\n\n")
            elif lc["type"] == "CLOAD":  # concentrated force in N
                for dof, mag in zip([1,2,3], lc["force_N"]):
                    if mag != 0:
                        f.write(f"*CLOAD\n{lc['node']}, {dof}, {mag:.4f}\n")
            elif lc["type"] == "GRAVITY":
                f.write(f"*DLOAD\nEALL, GRAV, {lc['magnitude_m_s2']:.4f}, "
                       f"{lc['direction'][0]}, {lc['direction'][1]}, {lc['direction'][2]}\n\n")

        # Output requests
        f.write("*EL FILE\nS, E, PEEQ\n")          # stress, strain, equiv plastic strain
        f.write("*NODE FILE\nU, RF\n")               # displacement, reaction force
        f.write("*END STEP\n")

    return output_path
```

## Step 3 — Run CalculiX and Parse Results

```python
import subprocess
import re
import numpy as np

def run_calculix(inp_path: str, n_cpu: int = 4) -> dict:
    """
    Execute CalculiX solver and return results dict.

    Returns:
    {
        "converged": bool,
        "von_mises_max_MPa": float,
        "displacement_max_mm": float,
        "reaction_forces_N": dict,    # node_set → [Fx, Fy, Fz] N
        "frd_path": str,              # binary results file
        "dat_path": str,              # text results file
        "solver_log": str,
    }
    """
    # CalculiX uses OMP for parallelism
    env = {"OMP_NUM_THREADS": str(n_cpu)}
    base = inp_path.replace(".inp", "")

    result = subprocess.run(
        ["ccx", "-i", base],
        capture_output=True, text=True, env={**os.environ, **env},
        timeout=3600  # 1 hour max
    )

    log = result.stdout + result.stderr

    # Check for convergence
    if "job finished" not in log.lower():
        raise RuntimeError(
            f"[FEA FAILED: CALCULIX ERROR]\n"
            f"CalculiX did not complete normally. Log tail:\n{log[-2000:]}"
        )

    # Parse .dat for summary results
    dat_path = base + ".dat"
    results = _parse_calculix_dat(dat_path)
    results["frd_path"] = base + ".frd"
    results["dat_path"] = dat_path
    results["solver_log"] = log
    results["converged"] = True
    return results


def _parse_calculix_dat(dat_path: str) -> dict:
    """Extract von Mises max, displacement max from CalculiX .dat file."""
    von_mises_max = 0.0
    displacement_max = 0.0

    with open(dat_path) as f:
        content = f.read()

    # Von Mises stress maximum
    for match in re.finditer(r"VON MISES.*?(\d+\.\d+[Ee][+-]\d+)", content):
        val = float(match.group(1))
        von_mises_max = max(von_mises_max, val)

    # Displacement magnitude maximum
    for match in re.finditer(r"DISPLACEMENTS.*?(\d+\.\d+[Ee][+-]\d+)", content):
        val = float(match.group(1))
        displacement_max = max(displacement_max, val)

    return {
        "von_mises_max_MPa": von_mises_max,
        "displacement_max_mm": displacement_max,
    }
```

## Step 4 — Structural Assessment

```python
def assess_structural_integrity(
    von_mises_max_MPa: float,
    displacement_max_mm: float,
    yield_strength_MPa: float,
    ultimate_strength_MPa: float,
    allowable_displacement_mm: float,
    load_factor: float = 1.5,         # safety factor on loads (ARP4761 / regulatory)
) -> dict:
    """
    Check structural adequacy. All values in MPa and mm.

    Safety factor (SF) definition:
        SF = σ_yield / σ_vonMises_max

    Minimum acceptable SF by domain:
    - Aerospace primary structure: SF ≥ 1.5 (FAR 25.303)
    - Secondary/non-primary: SF ≥ 1.25
    - Ground support: SF ≥ 2.0
    - Medical implant: SF ≥ 4.0 (fatigue-critical)
    """
    sf_yield   = yield_strength_MPa / max(von_mises_max_MPa, 1e-6)
    sf_ultimate = ultimate_strength_MPa / max(von_mises_max_MPa, 1e-6)
    disp_ok    = displacement_max_mm <= allowable_displacement_mm

    status = "pass"
    flags  = []

    if sf_yield < 1.5:
        status = "fail"
        flags.append(f"[FEA FAIL: SF_YIELD={sf_yield:.2f} < 1.5]")
    elif sf_yield < 2.0:
        flags.append(f"[FEA WARN: SF_YIELD={sf_yield:.2f} — marginal, review]")

    if not disp_ok:
        status = "fail"
        flags.append(
            f"[FEA FAIL: DISPLACEMENT {displacement_max_mm:.2f}mm > "
            f"ALLOWABLE {allowable_displacement_mm:.2f}mm]"
        )

    # Plasticity check (nonlinear FEA needed if von Mises exceeds yield)
    if von_mises_max_MPa > yield_strength_MPa:
        flags.append(
            "[FEA WARN: MATERIAL YIELDED — linear FEA invalid. "
            "Rerun with *PLASTIC material card or reduce loads.]"
        )

    return {
        "safety_factor_yield":    round(sf_yield, 3),
        "safety_factor_ultimate": round(sf_ultimate, 3),
        "displacement_check":     "pass" if disp_ok else "fail",
        "von_mises_max_MPa":      round(von_mises_max_MPa, 2),
        "displacement_max_mm":    round(displacement_max_mm, 3),
        "status":                 status,
        "flags":                  flags,
    }
```

## Step 5 — Mesh Convergence Study

Always run 3 mesh refinement levels before accepting a result:

```python
def convergence_study(
    stl_path: str,
    base_element_size_mm: float,
    **fea_kwargs,
) -> dict:
    """
    3-level mesh convergence study.
    Refine by factor 2× at each level.
    Accept if von Mises changes < 5% between finest two levels.
    """
    sizes = [base_element_size_mm, base_element_size_mm/2, base_element_size_mm/4]
    results = []

    for size in sizes:
        msh = generate_mesh(stl_path, size)
        inp = write_calculix_inp(msh, **fea_kwargs, output_path=msh.replace(".msh",".inp"))
        r   = run_calculix(inp)
        a   = assess_structural_integrity(r["von_mises_max_MPa"], **fea_kwargs)
        results.append({"size_mm": size, **r, **a})

    # Check convergence
    fine   = results[-1]["von_mises_max_MPa"]
    medium = results[-2]["von_mises_max_MPa"]
    change_pct = abs(fine - medium) / max(fine, 1e-6) * 100

    converged = change_pct < 5.0

    if not converged:
        print(
            f"[FEA WARN: MESH NOT CONVERGED] Von Mises change between mesh "
            f"levels: {change_pct:.1f}% > 5%. Refine further or investigate "
            f"stress concentration at geometric discontinuity."
        )

    return {
        "convergence_study": results,
        "mesh_converged": converged,
        "fine_mesh_result": results[-1],
        "convergence_change_pct": round(change_pct, 2),
    }
```

## Error Recovery

| Problem | Recovery |
|---|---|
| Geometry not watertight | Run `manifold2 repair` on STL; flag `[FEA BLOCKED: GEOMETRY NOT WATERTIGHT]` |
| CalculiX not installed | Fall back to FEniCS linear elasticity solver |
| Inverted mesh elements | Increase element size; smooth surface STL with `meshfix` |
| Non-convergence (nonlinear) | Reduce load increment; check contact; check material |
| Von Mises exceeds yield | Flag plastic; request nonlinear rerun with *PLASTIC card |
| Stress concentration spike | Investigate local geometry; may be mesh artefact vs real SCF |
| Mesh not converged (>5%) | Refine at stress concentration; use local mesh refinement |
