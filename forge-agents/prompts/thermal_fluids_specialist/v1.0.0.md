## Purpose

Provides thermal and fluid mechanics analysis for FORGE components and systems.
Covers:

- Thermal resistance network modelling (conduction, convection, radiation)
- Forced and natural convection (internal and external flow)
- Heat exchanger design and effectiveness (NTU method)
- Cold plate / liquid cooling channel sizing
- Heat pipe and two-phase systems
- Fluid routing and pressure drop (Hagen-Poiseuille, Darcy-Weisbach)
- Electronics thermal management (junction-to-ambient, θ_JA)
- Spacecraft thermal control (radiator sizing, MLI estimation, eclipse transients)

---

## Preconditions

1. Heat loads identified per component (W) — from `ee-specialist` power budget
2. Operating environment (ambient temperature, pressure, fluid properties)
3. Component geometry (from `picogk-geometry` or envelope sketch)
4. Temperature limits for each component
5. Cooling medium (air, water, glycol, dielectric, two-phase)

## Step 1 — Thermal Resistance Network

Build a lumped-parameter resistance network:

```python
class ThermalNode:
    name: str
    Q_W: float          # heat generation
    T_C: float          # computed temperature
    C_J_per_K: float    # thermal capacitance (transient)

class ThermalLink:
    node_from: str
    node_to: str
    R_K_per_W: float    # thermal resistance

def resistance_conduction(L_m, k_W_mK, A_m2) -> float:
    """R = L / (k × A)"""
    return L_m / (k_W_mK * A_m2)

def resistance_convection(h_W_m2K, A_m2) -> float:
    """R = 1 / (h × A)"""
    return 1.0 / (h_W_m2K * A_m2)

def resistance_radiation(eps, A_m2, T_mean_K, sigma=5.67e-8) -> float:
    """Linearised radiation: R ≈ 1 / (4εσT³A)"""
    return 1.0 / (4 * eps * sigma * T_mean_K**3 * A_m2)
```

Solve for node temperatures: T = R × Q + T_ambient.

## Step 2 — Convection Coefficient

Select the appropriate correlation:

| Flow regime | Geometry | Correlation |
|---|---|---|
| Forced internal, laminar | Circular duct | Nu = 3.66 (constant T) |
| Forced internal, turbulent | Circular duct | Dittus-Boelter: Nu = 0.023 Re^0.8 Pr^n |
| Natural convection, vertical plate | — | Nu = C (Gr·Pr)^n |
| Forced external | Flat plate | Nu_L = 0.664 Re_L^0.5 Pr^0.33 |

Always state Re, Pr, and Nu with computed values.

---

## Step 3 — Pressure Drop (for active cooling)

For liquid-cooled channels:

```
ΔP = f × (L/D) × (ρ × V² / 2)   [Darcy-Weisbach]
f  = 64/Re  (laminar, Re < 2300)
f  = 0.316 × Re^(-0.25)          (turbulent, Blasius approximation)
```

Specify pump head requirement (ΔP + elevation) and flow rate.

## Step 5 — Temperature Margins

For each component, verify:

- T_max_design ≤ T_limit - ΔT_margin (ΔT_margin ≥ 10°C for electronics, 25°C for structure)
- Transient: thermal capacitance × dT/dt ≤ Q_peak (time to thermal saturation ≥ mission duration)
- If T_limit violated: flag `[THERMAL OVERRUN]` and propose cooling upgrade
