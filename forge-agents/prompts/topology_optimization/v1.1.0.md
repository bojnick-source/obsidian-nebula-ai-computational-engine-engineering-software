**Agent:** topology_optimization
**Version:** 1.1.0
**Role:** workflow / structural-analysis
**Output contract:** `docs/contracts/agent-output-contract.md` (output_type: topology)
**Precedes:** picogk-geometry (provides density prescription)
**Follows:** component-generation (consumes component spec with load cases)
**Triggered by:** phrases "topology optimization", "TO", "minimum mass geometry",
  "optimize the structure", "find the optimal shape", "SIMP",
  "remove material where it's not needed", "find the structurally efficient shape"

---

## Purpose

Computes the optimal material distribution for a component given its boundary
conditions, load cases, and a target volume fraction. Output is a density
field that prescribes where material is structurally necessary — it is the
structural prescription for `picogk-geometry` to follow.

**Design intent:** Topology optimization finds where material is needed.
PicoGK geometry builds the shape that follows that prescription.
They are a pipeline, not alternatives.

This skill does NOT produce final geometry. It produces a density array and a
`topology_handoff` that tells `picogk-geometry` which regions should be solid,
which should use lattice infill, and which should be void.

## Solver Hierarchy

**Swan is the preferred solver.** Always attempt Swan first.

| Tier | Solver | Language | When to use |
|------|--------|----------|-------------|
| 1 | **Swan** (PRIMARY) | MATLAB | All production 3D runs. MATLAB available. Commercial license confirmed. |
| 2 | **FreeTO** (FALLBACK) | MATLAB / Octave | MATLAB unavailable or no Swan license. Octave-compatible. |
| 3 | ToPy | Python | No MATLAB/Octave. 2D and simple 3D problems. |
| 4 | OpenMDAO + pyOpt | Python | No MATLAB/Octave. Multi-load-case constrained problems. |
| 5 | scipy SIMP | Python | All above unavailable. Last resort only. Flag in vault. |

**Swan-specific capabilities (not available in FreeTO/ToPy/scipy):**
- Level-set topology optimization (sharper boundaries than density SIMP)
- Additive manufacturing (AM) constraints: overhang angle, support minimization,
  minimum feature size — natively enforced during optimization
- Anisotropic material optimization (critical for CFRP lay-up design)
- Metamaterial microstructure design (lattice unit cell optimization)
- Compliant mechanism synthesis
- Unstructured mesh support (complex geometry domains)

**FreeTO capabilities:**
- Density-based SIMP and SEMDOT methods
- Octave-compatible — no MATLAB commercial license required
- 1,263 LOC, MIT license (Osezua Ibhadode, University of Alberta)
- 2D and 3D support; adequate for validation runs and Octave environments
- Does NOT support level-set, AM constraints, or anisotropy

**Decision rule:** If the component is CFRP or requires AM manufacturing
constraints (Aladdin-3B fuselage, wing spar), Swan is mandatory for production
runs. FreeTO is acceptable for quick sanity checks and Octave environments.

## Preconditions

Verify all of these before writing any code:

1. **Component spec exists** in vault — produced by `component-generation`
2. **Load cases defined** — with magnitudes, directions, and application
   points. Qualitative descriptions ("under stress") are not sufficient.
3. **Boundary conditions defined** — where the component is fixed (DOFs
   constrained)
4. **Volume fraction target** — fraction of design space that may be
   material (typically 0.20–0.40 for aerospace; 60–80% material removal)
5. **Mesh resolution** — consistent with component size and minimum feature
   size

If load cases are missing or described only qualitatively, flag:
`[TO BLOCKED: LOADS REQUIRED]` and return to `component-generation`.
Do not proceed with assumed loads.

## Step 1 — Define the Design Space

The design space is the volume within which topology optimization operates.
It is NOT the same as the final geometry envelope — it is the maximum
permissible volume within which material may exist.

```python
class DesignSpaceParams:
    """
    Design space for topology optimization.

    The design space must:
    - Contain all potential load paths
    - Exclude non-design regions (interface attachments, cutouts)
    - Be meshed at appropriate resolution
    """
    # Outer design space (filled with design variable elements)
    length_mm: float = 850.0
    diameter_mm: float = 120.0

    # Non-design regions (frozen — always solid or always void)
    non_design_solid: list = [
        "motor_mount_bolt_bosses",    # always solid — load introduction
        "wing_spar_tube_interfaces",  # always solid — interface constraint
    ]
    non_design_void: list = [
        "payload_bay",                # always void — reserved for payload
        "fuel_line_routing_channel",  # always void — reserved for routing
    ]

    # Optimization target
    volume_fraction: float = 0.30    # 30% of design space may be material
    penalization: float = 3.0        # SIMP penalization (3.0 is standard)
    filter_radius_mm: float = 3.0    # minimum feature size (≥ 2× voxel size)

    # Convergence
    max_iterations: int = 200
    convergence_tol: float = 0.01    # max change in density between iterations
```

Non-design regions must be sourced from the component spec's interface
records (IF-XXX). Do not guess which regions are non-design.

## Step 2 — Select Solver

Check availability in tier order before writing any optimization code:

```python
def check_solver_availability() -> str:
    """
    Returns the name of the best available solver, in preference order.
    Swan (MATLAB) → FreeTO (MATLAB/Octave) → ToPy → OpenMDAO → scipy SIMP.
    """
    import subprocess, shutil

    # Tier 1: Swan (MATLAB)
    if shutil.which("matlab"):
        result = subprocess.run(
            ["matlab", "-batch", "try; swan_version; catch; exit(1); end"],
            capture_output=True, timeout=30
        )
        if result.returncode == 0:
            return "swan"

    # Tier 2: FreeTO (MATLAB or Octave)
    if shutil.which("octave") or shutil.which("matlab"):
        # FreeTO ships as freeto.m — check if it is on the MATLAB/Octave path
        result = subprocess.run(
            ["octave", "--eval", "which freeto"],
            capture_output=True, timeout=10
        )
        if result.returncode == 0:
            return "freeto"

    # Tier 3–5: Python solvers
    for name, module in [("topy", "topy"), ("openmdao", "openmdao")]:
        try:
            __import__(module)
            return name
        except ImportError:
            continue

    return "scipy_simp"   # last resort — flag in vault
```

Record the chosen solver in the vault frontmatter (`solver: swan`).

## Step 3A — Swan (PRIMARY: MATLAB, Level-Set + Density)

Swan is developed by CIMNE / UPC Barcelona. It is the primary solver for
all Aladdin-3B production runs. MATLAB required.

### Basic density-based run (SIMP via Swan)

```matlab
% Swan topology optimization — density method
% Run from MATLAB with Swan on the path

params = struct();
params.mesh_file      = 'mesh/C001_design_space.msh';  % Gmsh or .inp
params.volume_frac    = 0.30;
params.penalization   = 3.0;
params.filter_radius  = 3.0;   % mm
params.max_iter       = 200;
params.tol            = 0.01;

% Material: CFRP T300/epoxy (in-plane dominant)
params.E_longitudinal = 135e3;  % MPa
params.E_transverse   = 9.5e3;  % MPa
params.nu_12          = 0.28;
params.G_12           = 5.0e3;  % MPa
params.rho_kg_m3      = 1550;

% Load cases from component spec
params.loads = load_cases;        % Swan LoadCase struct array
params.boundary_conditions = bcs; % Swan BoundaryCondition struct array

result = Swan.run(params);

% Extract results
density    = result.density;          % (n_elements,) array, values in [0,1]
compliance = result.compliance_hist;  % convergence history
converged  = result.converged;        % boolean
iterations = result.n_iterations;
```

### AM-constrained run (overhang filter)

```matlab
% Enable AM constraints when component is additively manufactured
params.am_constraints.enabled         = true;
params.am_constraints.build_direction = [0, 0, 1];  % Z-up
params.am_constraints.max_overhang_deg = 45.0;       % standard AM limit
params.am_constraints.min_feature_mm  = 1.5;         % minimum printable feature

result = Swan.run(params);
% Swan enforces overhang and feature constraints during sensitivity filtering —
% no post-processing correction needed.
```

### Anisotropic CFRP optimization

```matlab
% For CFRP: optimize fibre orientation alongside topology
% Swan supports simultaneous material orientation + density optimization
params.material_type  = 'anisotropic';
params.orientations   = [0, 45, -45, 90];  % candidate ply angles (degrees)

result = Swan.run(params);
density      = result.density;
orientations = result.optimal_orientation;  % (n_elements,) ply angle per element
% Pass orientations to materials-specialist for lay-up sequencing
```

### Level-set method (sharp boundaries)

```matlab
% Use level-set for components where crisp solid/void boundaries are required
% (e.g., skin panels where intermediate density = unmanufacturable grey zones)
params.method = 'levelset';  % default is 'density' (SIMP)
params.levelset.reinit_freq = 5;

result = Swan.run(params);
density = result.density;  % Near-binary: values are ~0 or ~1
% Level-set results typically have less grey-zone than SIMP.
% Threshold at 0.5 for solid/void. Lattice regions are uncommon with level-set.
```

## Step 3B — FreeTO (FALLBACK: MATLAB/Octave, SIMP/SEMDOT)

FreeTO is the fallback solver. MIT license. Octave-compatible (no MATLAB
commercial license required). Written by Osezua Ibhadode, University of
Alberta. 1,263 LOC.

```matlab
% FreeTO topology optimization — SIMP method
% Compatible with both MATLAB and Octave

% Add FreeTO to path
addpath('/opt/freeto');

% Problem definition
nelx   = 150;        % elements in X
nely   = 50;         % elements in Y
nelz   = 50;         % elements in Z (3D)
volfrac = 0.30;
penal  = 3.0;
rmin   = 3.0;        % filter radius in elements

% 3D SIMP via FreeTO
[x, compliance_hist] = freeto_3d(nelx, nely, nelz, volfrac, penal, rmin, ...
    loads, fixed_dofs);

% 2D SIMP via FreeTO (quick 2D validation)
[x, compliance_hist] = freeto(nelx, nely, volfrac, penal, rmin, ...
    loads, fixed_dofs);

% SEMDOT (smooth-edged material distribution for optimizing topology)
% Better boundary resolution than standard SIMP; Octave-compatible
[x, compliance_hist] = freeto_semdot(nelx, nely, nelz, volfrac, penal, rmin, ...
    loads, fixed_dofs);
```

**FreeTO limitations vs Swan:**
- No level-set method (density only)
- No native AM manufacturing constraints — apply post-processing filter
- No anisotropic material optimization
- No unstructured mesh support (structured hexahedral grid only)
- Adequate for isotropic materials, 2D checks, and Octave environments

## Step 3C — scipy SIMP (LAST RESORT)

Use only when MATLAB/Octave and Python solvers (ToPy, OpenMDAO) are all
unavailable. Flag `solver: scipy_simp` in vault and note the limitation.

This is a complete 2D implementation based on Sigmund (2001):

```python
import numpy as np
from scipy.sparse import lil_matrix
from scipy.sparse.linalg import spsolve
from scipy.ndimage import uniform_filter

def simp_2d(
    nelx: int, nely: int,
    volfrac: float,
    penal: float,
    rmin: float,
    loads: np.ndarray,       # (ndof,) force vector
    fixed_dofs: list[int],
    E0: float = 1.0,         # normalized stiffness
    Emin: float = 1e-9,      # minimum stiffness — avoids FE singularity
    max_iter: int = 200,
    tol: float = 0.01,
) -> np.ndarray:
    """
    SIMP topology optimization for 2D problems.

    Returns density field of shape (nely, nelx) with values in [0, 1].
    Values near 1.0 = keep material. Values near 0.0 = remove material.

    Reference: Sigmund O (2001) "A 99 line topology optimization code
    written in Matlab", Struct Multidisc Optim 21:120–127.

    NOT suitable for 3D production runs — use Swan or FreeTO.
    """
    ndof = 2 * (nelx + 1) * (nely + 1)
    x = np.full((nely, nelx), volfrac)       # uniform density start
    KE = _element_stiffness_matrix()

    change = 1.0
    iteration = 0

    while change > tol and iteration < max_iter:
        iteration += 1
        x_old = x.copy()

        K = _assemble_global_K(x, KE, E0, Emin, penal, nelx, nely)
        free_dofs = [i for i in range(ndof) if i not in fixed_dofs]
        u = np.zeros(ndof)
        u[free_dofs] = spsolve(
            K[np.ix_(free_dofs, free_dofs)],
            loads[free_dofs]
        )

        dc = _compute_sensitivities(u, x, KE, E0, Emin, penal, nelx, nely)
        dc = _filter_sensitivities(x, dc, rmin)
        x = _oc_update(x, dc, volfrac)

        change = np.max(np.abs(x - x_old))

        if iteration % 20 == 0:
            compliance = float(loads @ u)
            print(f"  Iter {iteration:3d}: compliance={compliance:.4f}, "
                  f"vol={x.mean():.4f}, change={change:.6f}")

    print(f"Converged after {iteration} iterations (change={change:.6f})")
    return x


def _element_stiffness_matrix() -> np.ndarray:
    """Q4 element stiffness matrix for plane stress, E=1, nu=0.3."""
    E, nu = 1.0, 0.3
    k = np.array([
        1/2 - nu/6,   1/8 + nu/8,  -1/4 - nu/12, -1/8 + 3*nu/8,
       -1/4 + nu/12, -1/8 - nu/8,   nu/6,          1/8 - 3*nu/8,
    ])
    return E/(1-nu**2) * np.array([
        [ k[0], k[1], k[2], k[3], k[4], k[5], k[6], k[7]],
        [ k[1], k[0], k[7], k[6], k[5], k[4], k[3], k[2]],
        [ k[2], k[7], k[0], k[5], k[6], k[3], k[4], k[1]],
        [ k[3], k[6], k[5], k[0], k[7], k[2], k[1], k[4]],
        [ k[4], k[5], k[6], k[7], k[0], k[1], k[2], k[3]],
        [ k[5], k[4], k[3], k[2], k[1], k[0], k[7], k[6]],
        [ k[6], k[3], k[4], k[1], k[2], k[7], k[0], k[5]],
        [ k[7], k[2], k[1], k[4], k[3], k[6], k[5], k[0]],
    ])
```

For 3D problems, use Swan (Tier 1) or FreeTO (Tier 2).
scipy SIMP is 2D only for production work.

## Step 4 — Interpret Results

After optimization converges, classify the density field:

```python
def interpret_density_field(
    density: np.ndarray,
    threshold_solid: float = 0.5,
    threshold_lattice: float = 0.2,
) -> dict:
    """
    Classify elements into solid, lattice, and void regions.
    Returns interpretation dict consumed by picogk-geometry.

    Note: Level-set results from Swan produce near-binary densities.
    Lattice regions (0.2–0.5) will be small when using level-set method.
    Lattice regions are more common with SIMP/SEMDOT density methods.
    """
    solid_fraction   = (density >= threshold_solid).mean()
    lattice_fraction = ((density >= threshold_lattice) &
                        (density < threshold_solid)).mean()
    void_fraction    = (density < threshold_lattice).mean()

    # Critical: verify load paths are continuous
    # A disconnected solid region means the structure cannot transmit load —
    # the result is physically invalid, not just sub-optimal.
    from scipy import ndimage
    labeled, n_components = ndimage.label(density >= threshold_solid)
    load_path_connected = (n_components == 1)

    return {
        "solid_fraction":      solid_fraction,
        "lattice_fraction":    lattice_fraction,
        "void_fraction":       void_fraction,
        "load_path_connected": load_path_connected,
        "n_solid_components":  n_components,
        "recommendation": {
            "use_solid_geometry": solid_fraction > 0.7,
            "use_lattice_infill": 0.2 < solid_fraction <= 0.7,
            "mass_reduction_pct": (1.0 - solid_fraction) * 100,
        },
    }
```

**Critical check:** if `load_path_connected` is `False`, the result is
invalid. Do not pass a disconnected topology to `picogk-geometry`. The
cause is one of:

- Volume fraction too low → increase `volume_fraction`
- Load cases or boundary conditions incorrectly specified → return to
  `component-generation` with `[TO BLOCKED: LOADS REQUIRED]`
- Design space excludes a necessary load path → revise non-design regions

## Error Recovery

| Problem | Recovery |
|---|---|
| Swan not available (MATLAB missing) | Fall back to FreeTO (Octave); flag `solver_downgrade: swan→freeto` in vault |
| FreeTO not available (no MATLAB/Octave) | Fall back to ToPy then scipy SIMP; flag in vault |
| Density field checkerboard pattern | Filter radius too small; increase `rmin` to ≥ 3× voxel size |
| Load path disconnected | Increase volume fraction; check BCs; check design space excludes too much |
| Optimization does not converge | Check for rigid body motion in FE model (BC error); try larger filter radius |
| 3D scipy SIMP too slow | Use Swan or FreeTO for 3D; scipy SIMP is 2D only |
| Volume fraction achieved ≠ target | OC update rarely converges to exact target; accept ±2% and note in vault |
| Qualitative loads only | Flag `[TO BLOCKED: LOADS REQUIRED]`; return to component-generation |
| AM constraints diverge (Swan) | Relax overhang limit by 5° increments; check build direction vector |
| CFRP anisotropy not converging | Reduce orientation candidates to {0, 90}; add ±45 after convergence |

## What This Skill Does NOT Do

- Does **not** generate final geometry — produces a density prescription that
  `picogk-geometry` turns into solid geometry
- Does **not** validate the optimized geometry structurally — run
  `simulation-fea` on the final geometry after PicoGK builds it from the
  topology result
- Does **not** optimize for multiple objectives simultaneously (mass,
  stiffness, thermal resistance) — flag `[MULTI-OBJECTIVE: define priority
  weighting before proceeding]`
- Does **not** optimize for manufacturing constraints unless using Swan with
  AM constraints enabled — for FreeTO/ToPy/scipy, manufacturing feasibility
  is not guaranteed by the optimizer and must be checked post-hoc
- Does **not** replace engineering judgment about design space definition —
  a poorly defined design space produces unmanufacturable or physically
  meaningless topology
