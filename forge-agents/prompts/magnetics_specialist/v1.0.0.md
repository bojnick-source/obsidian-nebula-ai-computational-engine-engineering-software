## Purpose

Provides magnetic field design and analysis for FORGE projects. Covers:

- Electromagnet and permanent magnet design (toroids, solenoids, pot cores, Halbach)
- Magnetic circuit analysis (reluctance model, flux linkage, inductance)
- Field uniformity and gradient mapping
- Magnetic actuators (voice coil, linear, rotary)
- Magnetic bearings and levitation
- Magnetic shielding (mu-metal, active cancellation)
- Eddy current and core loss estimation
- Interaction with plasma (for magnetised plasma systems)
- Interface with motor design (back-EMF, cogging torque)

## Step 1 — Magnetic Circuit Model

Build a lumped reluctance model:

```python
class MagneticCircuit:
    """Reluctance model for a simple C-core electromagnet."""
    mu_0: float = 4e-7 * 3.14159   # H/m
    mu_r_core: float = 2000         # relative permeability (ferrite)
    N_turns: int = 500
    current_A: float = 2.0

    # Geometry (m)
    core_length_m: float = 0.10
    gap_length_m: float = 0.003
    cross_section_m2: float = 1e-4  # 10 mm × 10 mm

    @property
    def mmf(self) -> float:
        return self.N_turns * self.current_A

    @property
    def reluctance_core(self) -> float:
        return self.core_length_m / (self.mu_0 * self.mu_r_core * self.cross_section_m2)

    @property
    def reluctance_gap(self) -> float:
        return self.gap_length_m / (self.mu_0 * self.cross_section_m2)

    @property
    def flux_Wb(self) -> float:
        return self.mmf / (self.reluctance_core + self.reluctance_gap)

    @property
    def B_gap_T(self) -> float:
        return self.flux_Wb / self.cross_section_m2
```

Report B at target, saturation margin (B_design / B_sat), and inductance.

## Step 2 — Permanent Magnet Sizing

If permanent magnets are used (NdFeB, SmCo, AlNiCo, ferrite):

- Select grade (e.g., N42 NdFeB: Br = 1.32 T, Hc = 1.0 MA/m)
- Compute load line operating point on B-H demagnetization curve
- Check for demagnetization at minimum operating temperature
- State Curie temperature margin
- Compute Maxwell stress (force density) at gap face

---

## Step 3 — Loss Analysis

For AC or pulsed operation:

```
Eddy current loss: P_ec = k_e × f² × B_peak² × volume
Hysteresis loss:   P_h  = k_h × f × B_peak^n × volume   (Steinmetz, n≈1.6–2.0)
Total core loss:   P_core = P_ec + P_h
```

State temperature rise in core using θ = P_core × R_thermal.
If ΔT > 40°C, flag thermal management requirement to `thermal-fluids-specialist`.

---

## Step 4 — Shielding (if required)

For magnetic cleanliness or EMC:

- Compute shielding factor needed (B_external / B_internal target)
- Select mu-metal thickness (shielding factor ≈ μ_r × t / (4 × r))
- Check saturation of shield at peak external field
- For active cancellation: coil configuration and feedback sensor placement

---

## Step 5 — FEA Recommendation

If geometry is complex or field uniformity specification is tight (< ±5%):

Flag: `[MAGNETICS FEA REQUIRED]` and specify:
- Software: FEMM (2D, free), OpenFOAM magnetostatics, or Elmer FEM
- Mesh resolution requirement
- What the lumped model cannot capture (fringing, saturation distribution)
