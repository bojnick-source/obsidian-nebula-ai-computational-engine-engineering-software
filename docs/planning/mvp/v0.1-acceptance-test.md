# v0.1 Acceptance Test

> This test must pass for the v0.1 milestone gate to be declared complete.

---

## Test Scenario

**Component:** Aladdin-3B motor mount bracket
**Analysis type:** Linear static FEA
**Material:** 6061-T6 aluminum (E=68.9 GPa, σ_yield=276 MPa)
**Load:** Maximum static thrust (10N representative test load)
**Pass criterion:** Max von Mises stress < 165.6 MPa (0.6 × 276 MPa)

## Acceptance Criteria

- [ ] Task receives a trace ID at intake

- [ ] Trace ID is the same across all artifacts

### AC-02: ME Specialist Output
- [ ] ME specialist produces an output conforming to agent-output-contract.md v1
- [ ] Output contains: findings with units, confidence, provenance
- [ ] Assumptions explicitly listed (not null)
- [ ] `what_would_falsify` field populated

### AC-03: GMSH Wrapper
- [ ] GMSH wrapper invoked via MCP envelope v1
- [ ] Mesh generated and validated (non-zero elements, no degenerate elements)
- [ ] Output envelope status: `success`
- [ ] Result written to blackboard

### AC-04: CalculiX Wrapper
- [ ] CalculiX wrapper invoked via MCP envelope v1

- [ ] Output envelope status: `success`

### AC-05: Verification Stack
- [ ] Contract Gate: PASS

- [ ] Dimensional Gate: PASS
- [ ] Provenance Gate: PASS (6061-T6 properties cited from ASM/Matweb)

### AC-06: Vault Persistence
- [ ] Note written to `forge-vault/projects/aladdin-3b/components/`
- [ ] Frontmatter conforms to vault-frontmatter-schema.md v1
- [ ] Note type: `finding`
- [ ] Provenance, units, confidence, trace_id all populated

### AC-07: Amnesia Check
- [ ] Retrieval sanity test passes immediately after write

### AC-08: Output Report
- [ ] Final output contains: result_summary, unresolved_gaps, what_would_falsify, confidence, artifact_refs
- [ ] Status: `complete` or `degraded` (not `failed`)
- [ ] Confidence score populated (0.0–1.0)

### AC-09: No Unverified Data in Vault
- [ ] Any run where a verification gate fails: vault write is blocked
- [ ] Failure documented in JSONL log with error_code

### AC-10: JSONL Log Completeness
- [ ] All 9 core loop phases emit start + end events
- [ ] All error events include error_code
- [ ] No phase missing trace_id
