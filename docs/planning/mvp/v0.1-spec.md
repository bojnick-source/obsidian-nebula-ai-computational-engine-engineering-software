# FORGE v0.1 MVP Spec

> **Status:** P0 — freeze candidate
> **Target:** Single-discipline structural analysis, Aladdin-3B motor mount bracket, end-to-end traced and persisted.

---

## Goal

Demonstrate a complete FORGE task cycle for one engineering component: task intake → structural analysis by ME specialist → FEA mesh (GMSH) → FEA solve (CalculiX) → verification → vault persistence → structured output.

No LLM, no agent, no tool output enters the vault without passing verification.

---

## In-Scope (v0.1)

### Core Runtime
- [ ] Blackboard (typed entry, schema v1, concurrent-safe reads/writes)
- [ ] Config loader (YAML, schema versioning)
- [ ] Model router (single provider, no failover required)
- [ ] JSONL logger with trace ID propagation
- [ ] Error code emission

### Agent System
- [ ] ME Specialist (prompt v1.0.0, structural analysis only)
- [ ] Librarian (intake + retrieval + amnesia check)

### Tools
- [ ] GMSH MCP wrapper (mesh generation, basic validation)
- [ ] CalculiX MCP wrapper (linear static FEA, result parsing)

### Verification
- [ ] Contract Gate
- [ ] Unit Gate
- [ ] Dimensional Gate
- [ ] Provenance Gate

### Memory
- [ ] Vault write (frontmatter schema v1, `finding` note type)
- [ ] Vault read (retrieval by domain + component)
- [ ] Amnesia check (post-write retrieval sanity test)

### Orchestration
- [ ] Task intake → trace ID assignment → blackboard init
- [ ] Phase sequencing (phases 0–9 per core-loop.md)
- [ ] Loop guard (max 5 iterations)

---
