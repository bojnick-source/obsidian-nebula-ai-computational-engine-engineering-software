# FORGE Catalog v8 — Execution Addendum

> This addendum was integrated into v8+ (current). Kept here for historical reference.

---

## Key Additions in v8

### Build Lane Framework
Introduced the 10 build lanes (A–J) as the execution view of FORGE development. Lanes provide a sequenced, prioritized view of what to build and when.

### P0/P1/P2 Tagging System
Every planning item tagged with a priority:
- P0: must be frozen before build starts
- P1: finalize during build
- P2: future planning

### Planning Cut Line
Explicit list of what is excluded from MVP. Prevents scope creep. See `docs/planning/mvp/mvp-cut-line.md`.

### Addendum Intake Rules
Process for adding new planning items after baseline freeze. Prevents indefinite planning expansion.

### Normalization Schedule
Schedule for integrating addenda into the main catalog and retiring fragments.
