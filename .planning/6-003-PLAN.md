## Objective

Implement `forge_agent/agents/synthesis.py` — an LLM-backed agent that consolidates
multiple vault notes into a single synthesis note conforming to the Agent Output
Contract and Vault Frontmatter Schema v1.

The synthesis agent:
- Accepts `notes: list[dict]` (each with `path`, `content`, `frontmatter`)
- Produces a unified `synthesis_output: dict` with all required contract fields
- Writes the synthesis note to the vault via `LibrarianAgent.intake()` with
  `type: synthesis` frontmatter

This closes the Lane C memory gap (synthesis missing from Tier 2 V1 build list).

## Acceptance criteria

1. `SynthesisAgent(client, librarian).synthesize(notes, domain, task_id, trace_id)`
   returns a `SynthesisResult` with fields:
   `summary: str`, `key_equations: list[str]`, `cross_domain_links: list[str]`,
   `gaps: list[str]`, `confidence: float`, `vault_path: str`.
2. `SynthesisResult.vault_path` is non-empty — the note was written to vault.
3. The dict passed to `librarian.intake()` has `type == "synthesis"` in its
   frontmatter.
4. The dict passed to `librarian.intake()` contains all Agent Output Contract
   required fields: `model_choice`, `equations`, `units`, `sanity_checks`,
   `calculation_path`.
5. `synthesize()` raises `ValueError` if `notes` is empty or has fewer than 2 entries
   (synthesis of a single note is a no-op).
6. `SynthesisAgent` works with a mocked Anthropic client and mocked LibrarianAgent
   (no live API in tests).
7. pytest: ≥ 8 new tests in `forge_agent/tests/test_synthesis_agent.py`;
   full suite passes (≥ 494 + 8 = 502 tests, stacking on 6-001 + 6-002).

## Implementation steps

1. **Create `forge_agent/agents/synthesis.py`**:

   ```python
   ROLE = "synthesis_agent"
   MODEL = "claude-opus-4-6"
   TEMPERATURE = 0.1

   SYSTEM_PROMPT = """\
   You are the FORGE Synthesis Agent. You consolidate engineering vault notes into a
   single coherent synthesis. Always: state model assumptions, list governing equations
   in LaTeX, use SI units throughout, provide at least one sanity check, and show the
   derivation path. Identify cross-domain links and knowledge gaps.

   Return JSON with these fields (Agent Output Contract required):
   {
     "model_choice": "...",
     "equations": ["...", ...],
     "units": "SI throughout",
     "sanity_checks": ["..."],
     "calculation_path": "...",
     "summary": "...",
     "key_equations": ["..."],
     "cross_domain_links": ["..."],
     "gaps": ["..."],
     "confidence": 0.0
   }
   """
   ```

   `SynthesisResult` dataclass: `summary`, `key_equations`, `cross_domain_links`,
   `gaps`, `confidence`, `vault_path`.

   `SynthesisAgent.__init__(self, client, librarian)`:
   - Store `self._client` and `self._librarian` — both used in `synthesize()` (P2 guard).

   `synthesize(notes, domain, task_id, trace_id) → SynthesisResult`:
   - Raise `ValueError` if `len(notes) < 2`.
   - Build prompt: concatenate note contents (truncated to 2000 chars each, max 5 notes).
   - Call LLM; parse JSON.
   - Build intake dict with frontmatter `type="synthesis"`, `domain=domain`,
     `trace_id=trace_id`, `task_id=task_id`, plus all Agent Output Contract fields.
   - Call `self._librarian.intake(intake_dict)` → vault_path.
   - Return `SynthesisResult(vault_path=vault_path, ...)`.

2. **Write tests** in `forge_agent/tests/test_synthesis_agent.py`:
   - `synthesize()` with 2 valid notes → SynthesisResult with vault_path set.
   - `synthesize()` calls `librarian.intake()` with `type=="synthesis"`.
   - Contract fields all present in intake dict.
   - `synthesize([one_note], ...)` raises `ValueError`.
   - Mocked LLM response with partial JSON still produces a result (graceful fallback).

## Known risks

- **P1 (interface mismatch)**: `SynthesisAgent` calls `self._librarian.intake(note_dict)`.
  Verify `LibrarianAgent.intake()` accepts a `dict` (not path, not list).
  Check `forge_agent/agents/librarian.py` signature before implementing.
- **P2 (ignored param)**: `domain`, `task_id`, and `trace_id` must all appear in the
  intake dict frontmatter — never accepted and silently dropped.
- **P7 (error codes)**: N/A — no error codes emitted directly by synthesis agent;
  vault write failures propagate from LibrarianAgent.
