## Objective

Extend the static verification stack in `forge_agent/core/verifier.py` with two new
gates:

1. **ContradictionGate** — detects internally contradictory findings within a single
   specialist output (same quantity declared with conflicting verdicts). Optionally
   checks the new output against a list of existing vault notes.
2. **AssumptionGate** — detects hidden assumptions: `calculation_path` mentions
   "assum*" but no `assumptions` list is declared in the output.

Both gates return `GateResult` (already defined in verifier.py) and use error codes
from `docs/contracts/error-codes.md`.

`run_all_gates()` is extended with an optional `vault_notes` parameter
(backward-compatible — defaults to `None`) so callers can pass existing vault notes
for contradiction checking without breaking existing tests.

## Acceptance criteria

1. `ContradictionGate.check(output)` returns `passed=True` for an output with no
   conflicting findings.
2. `ContradictionGate.check(output)` returns `passed=False, error_code="ERR_CONTRADICTION_DETECTED"`
   when two findings share the same `quantity` but have verdicts `"pass"` and `"fail"`.
3. `ContradictionGate.check(output, vault_notes=[...])` returns `passed=False` when
   a finding's `value` (numeric) for a `quantity` differs by > 20% from the same
   quantity in any vault note.
4. `AssumptionGate.check(output)` returns `passed=True` for output with no
   "assum*" language in `calculation_path`.
5. `AssumptionGate.check(output)` returns `passed=False, error_code="ERR_VERIFY_HIDDEN_ASSUMPTION"`
   when `calculation_path` contains "assuming" but `output` has no `assumptions` field
   (or it is empty).
6. `run_all_gates(output)` (no vault_notes) returns 6 results (4 existing + 2 new);
   all existing tests still pass (backward compat).
7. `run_all_gates(output, vault_notes=[...])` returns 6 results and invokes
   ContradictionGate with the provided notes.
8. pytest: ≥ 8 new tests in `forge_agent/tests/test_verifier_gates.py`;
   full suite passes (≥ 478 + 8 = 486 tests).

## Implementation steps

1. **Add ContradictionGate class** to `forge_agent/core/verifier.py` after
   `ProvenanceGate`:
   - `check(cls, output: dict, vault_notes: list[dict] | None = None) → GateResult`
   - Intra-output check: group findings by `quantity`; if any group has both
     `verdict="pass"` and `verdict="fail"`, return FAIL.
   - Vault check (only if `vault_notes` is not None): for each finding with a
     numeric `value`, compare against same `quantity` in each vault note's findings;
     if abs(delta) / max(abs(new), abs(old)) > 0.20, return FAIL.
   - All paths that accept `vault_notes` must actually use the parameter (P2 guard).

2. **Add AssumptionGate class** after ContradictionGate:
   - `check(cls, output: dict) → GateResult`
   - Extract `calculation_path` string; scan for word-boundary match of `assum`
     (case-insensitive) using `re.search(r'\bassum', text, re.IGNORECASE)`.
   - If match found and `output.get("assumptions")` is falsy, return
     `GateResult(gate="AssumptionGate", passed=False,
     error_code="ERR_VERIFY_HIDDEN_ASSUMPTION", detail=...)`.

3. **Extend `run_all_gates()`**:
   ```python
   def run_all_gates(
       output: dict,
       vault_notes: list[dict] | None = None,
   ) -> list[GateResult]:
   ```
   Append after ProvenanceGate:
   ```python
   results.append(ContradictionGate.check(output, vault_notes))
   results.append(AssumptionGate.check(output))
   ```

4. **Write tests** in `forge_agent/tests/test_verifier_gates.py`:
   - ContradictionGate: pass (no conflicts), fail (intra conflicts), pass (vault no
     conflict), fail (vault >20% delta).
   - AssumptionGate: pass (no assum*), pass (assum* + assumptions field present),
     fail (assum* no assumptions field).
   - `run_all_gates` returns 6 results; backward-compat (no vault_notes kwarg still works).

## Known risks

- **P1 (interface mismatch)**: `run_all_gates` callers in `pipeline.py` call it as
  `run_all_gates(output)` — new optional param must default to `None` so all existing
  calls remain valid. Verify with `grep -n "run_all_gates" forge_agent/` before commit.
- **P2 (ignored param)**: `vault_notes` in ContradictionGate must be read in both the
  intra-output path AND the vault-comparison path — never accepted but silently ignored.
- **P7 (error code)**: Use `ERR_CONTRADICTION_DETECTED` and `ERR_VERIFY_HIDDEN_ASSUMPTION`
  exactly as spelled in `docs/contracts/error-codes.md`.
