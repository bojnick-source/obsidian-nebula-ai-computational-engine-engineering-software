## Objective

Implement `forge_agent/core/live_tool_executor.py` — a `LiveToolExecutor` class
that exercises the **real Python code paths** for GMSH and CalculiX, including
the `ImportError` / `PATH` checks that exist in the MCP wrapper modules.

Unlike `DefaultToolExecutor` (which returns a simplified `{"status": "degraded", ...}`
dict on absence), `LiveToolExecutor` returns **full MCP Wrapper Envelope v1** dicts
using `error_envelope()` / `success_envelope()` from
`forge_agent/mcp_wrappers/_envelope.py`. This validates the end-to-end envelope
contract in the degraded environment that CI runs in.

The executor does NOT call MCP servers over network/subprocess transport. It calls
the inner logic of the wrapper modules directly by importing module-level helpers.
For the Phase 3 environment (gmsh pkg absent, ccx binary absent), both methods
will consistently return `error_envelope(...)` with `error_code =
"ERR_TOOL_SUBPROCESS_FAIL"`.

## Acceptance Criteria

1. `pytest forge_agent/tests/test_live_tool_executor.py -v` exits 0.
2. `LiveToolExecutor().run_gmsh(trace_id=..., task_id=..., invocation_id=...)`
   returns a dict with `"$schema": "forge/mcp/response/v1"` in **all** cases
   (gmsh installed or absent).
3. When `gmsh` Python package is not importable, `run_gmsh()` returns a dict
   where `status in {"error", "degraded"}` and `error_code ==
   "ERR_TOOL_SUBPROCESS_FAIL"`.
4. `LiveToolExecutor().run_calculix(trace_id=..., task_id=..., invocation_id=...)`
   returns a dict with `"$schema": "forge/mcp/response/v1"` in all cases.
5. When `ccx` / `ccx_2.22` is not on PATH, `run_calculix()` returns
   `status in {"error", "degraded"}` and `error_code ==
   "ERR_TOOL_SUBPROCESS_FAIL"`.
6. `trace_id` and `invocation_id` from the call arguments appear verbatim in the
   returned envelope dict (verified by unit test).
7. `ruff check forge_agent/core/live_tool_executor.py --ignore E501` exits 0.

## Design

```
LiveToolExecutor
  run_gmsh(trace_id, task_id, invocation_id, geo_file="", **kwargs) -> dict
  run_calculix(trace_id, task_id, invocation_id, input_file="", **kwargs) -> dict
```

Both methods follow this pattern:

1. Attempt the real operation (try import gmsh / shutil.which("ccx")).
2. On failure, call `error_envelope(TOOL_ID, WRAPPER_VERSION, trace_id,
   invocation_id, error_code, error_detail, duration_ms)` and return it.
3. On success, call `success_envelope(...)` and return it.

Key import: `from forge_agent.mcp_wrappers._envelope import error_envelope,
success_envelope`.

For `run_gmsh`: attempt `import gmsh`; if `ImportError`, return
`error_envelope(...)` with `error_code="ERR_TOOL_SUBPROCESS_FAIL"`.
If geo_file is empty or does not exist, also return error_envelope with
`error_code="ERR_TOOL_SUBPROCESS_FAIL"`. Otherwise call
`gmsh.initialize()` / `gmsh.merge()` / `gmsh.model.mesh.generate()` /
`gmsh.write()` in a try/finally that always calls `gmsh.finalize()`.

For `run_calculix`: check `shutil.which("ccx") or shutil.which("ccx_2.22")`;
if None, return `error_envelope(...)` with `error_code="ERR_TOOL_SUBPROCESS_FAIL"`.
If `input_file` does not exist, return error_envelope. Otherwise run via
`asyncio.run(_run_ccx(...))` using the logic from `calculix_server._run_ccx`
(duplicate just the subprocess invocation, or import the private helper).

**P2 guard**: `task_id` is used by writing it into the `metadata` dict so no
parameter is silently dropped. `geo_file` and `input_file` are inspected (Path
existence check), not ignored.

**P1 guard**: All methods called on `_envelope.py` (`error_envelope`,
`success_envelope`) are confirmed to exist in that module before writing.
Method signatures verified from `_envelope.py` lines 55–79.

## Implementation Steps

1. Create `forge_agent/core/live_tool_executor.py`:
   - Import `shutil`, `time`, `asyncio`, `uuid` and envelope factories.
   - Define `TOOL_ID_GMSH = "gmsh"`, `TOOL_ID_CCX = "calculix"`,
     `WRAPPER_VERSION = "1.0.0"`.
   - Implement `class LiveToolExecutor` with `run_gmsh(...)` and
     `run_calculix(...)` per the design above.
   - Both methods must use `task_id` (write to metadata) to satisfy P2.

2. Create `forge_agent/tests/test_live_tool_executor.py`:
   - `test_run_gmsh_returns_full_schema_envelope` — call `run_gmsh()` without
     gmsh installed; assert `result["$schema"] == "forge/mcp/response/v1"`.
   - `test_run_gmsh_absent_returns_error_envelope` — assert
     `result["status"] in {"error", "degraded"}` and
     `result["error_code"] == "ERR_TOOL_SUBPROCESS_FAIL"`.
   - `test_run_gmsh_propagates_trace_id` — assert
     `result["trace_id"] == trace_id`.
   - `test_run_calculix_returns_full_schema_envelope` — same pattern for ccx.
   - `test_run_calculix_absent_returns_error_envelope` — ccx not on PATH in CI.
   - `test_run_calculix_propagates_trace_id`.
   - `test_envelope_has_tool_id_and_wrapper_version` — assert
     `result["tool_id"]` and `result["wrapper_version"]` are populated.

## Known Risk

- **P1**: `error_envelope()` and `success_envelope()` signatures verified from
  `forge_agent/mcp_wrappers/_envelope.py`. Parameters:
  `(tool_id, wrapper_version, trace_id, invocation_id, error_code, error_detail,
  duration_ms, status="error", exit_code=-1)`. Do not pass positional args out
  of order.
- **P2**: `task_id` must be used — write it into `metadata` dict in the envelope
  or use it to build `invocation_id` if not provided. Never accept it silently.
- **P3**: Not applicable — no circuit breaker in this executor.
- **Language**: Python only. This is MCP tool dispatch; polyglot doctrine
  permits Python for MCP wrappers and tool integration.
