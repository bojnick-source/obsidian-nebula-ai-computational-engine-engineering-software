## Objective

Implement `forge_agent/core/memory_decay.py` — a deterministic (no LLM) module that
scans vault notes for staleness and tags stale notes by calling `vault_manager.upsert_note()`.

This closes the Lane C memory gap (decay detection missing from Tier 2 V1 build list).

Staleness is defined as: last_updated timestamp in frontmatter is more than
`days_threshold` days before the scan date. Default threshold: 90 days.

## Acceptance criteria

1. `MemoryDecayDetector.scan_stale_notes(notes, scan_date, days_threshold=90)`
   returns a `list[StaleNote]` containing only notes where
   `(scan_date - last_updated).days > days_threshold`.
2. `StaleNote` has fields: `path: str`, `last_updated: datetime`, `days_stale: int`,
   `domain: str`.
3. Notes without a `last_updated` field in frontmatter are treated as stale with
   `days_stale = days_threshold + 1` (conservative: assume stale when unknown).
4. `MemoryDecayDetector.flag_stale(vault_manager, stale_notes)` calls
   `vault_manager.upsert_note(path, markdown, frontmatter)` exactly once per stale note,
   with `frontmatter["status"] == "stale"`.
5. `flag_stale()` returns `list[str]` of flagged note paths.
6. `flag_stale()` is a no-op (returns `[]`) when `stale_notes` is empty.
7. Both `scan_stale_notes()` and `flag_stale()` are pure Python with no LLM dependency
   (deterministic, fully testable without mocks).
8. pytest: ≥ 8 new tests in `forge_agent/tests/test_memory_decay.py`;
   full suite passes (≥ 502 + 8 = 510 tests, stacking on 6-001 + 6-002 + 6-003).

## Implementation steps

1. **Create `forge_agent/core/memory_decay.py`**:

   ```python
   from __future__ import annotations
   from dataclasses import dataclass
   from datetime import datetime, timezone
   from typing import Any
   ```

   `StaleNote` dataclass: `path: str`, `last_updated: datetime`,
   `days_stale: int`, `domain: str`.

   `MemoryDecayDetector` class:

   `scan_stale_notes(notes: list[dict], scan_date: datetime, days_threshold: int = 90) → list[StaleNote]`:
   - `notes`: list of dicts with keys `"path"`, `"frontmatter"` (dict), optionally
     `"content"`.
   - For each note, read `frontmatter.get("updated_at")` (ISO 8601 string) or
     `frontmatter.get("last_updated")` — try both keys for compatibility with vault
     frontmatter schema.
   - Parse to `datetime` (UTC-aware). If parse fails or key missing, set
     `last_updated = scan_date - timedelta(days=days_threshold + 1)`.
   - Compute `days_stale = (scan_date - last_updated).days`.
   - Include in results only if `days_stale > days_threshold`.
   - Use `frontmatter.get("domain", "unknown")` for `StaleNote.domain`.
   - All parameters (`notes`, `scan_date`, `days_threshold`) must be read (P2 guard).

   `flag_stale(vault_manager: Any, stale_notes: list[StaleNote]) → list[str]`:
   - For each `StaleNote`, read its existing `path`; build updated frontmatter
     with `{"status": "stale", "days_stale": note.days_stale}`.
   - Build minimal markdown: `f"# Stale Note\n\n> Last updated: {note.last_updated.isoformat()}\n> Days stale: {note.days_stale}\n"`.
   - Call `vault_manager.upsert_note(note.path, markdown, frontmatter)`.
   - Append `note.path` to results.
   - Return results (empty list if `stale_notes` is empty — P2: `stale_notes` is
     always iterated, never ignored).

2. **Write tests** in `forge_agent/tests/test_memory_decay.py`:
   - scan: note with `updated_at` 100 days ago is stale (default 90 threshold).
   - scan: note updated 10 days ago is not stale.
   - scan: note missing `updated_at` is treated as stale.
   - scan: `days_threshold=30` tightens the window.
   - scan: returns correct `days_stale` value and `domain` from frontmatter.
   - flag: `upsert_note` called once per stale note with `status=="stale"`.
   - flag: empty input → empty output, no vault calls.
   - flag: returned list equals note paths.

## Known risks

- **P1 (interface mismatch)**: `flag_stale()` calls `vault_manager.upsert_note(path, markdown, frontmatter)`.
  Verify that `ObsidianVaultManager.upsert_note` accepts exactly these three positional
  args in this order. Check `forge_agent/agents/librarian.py` and
  `forge_agent/core/ilc_detector.py` for the call pattern already used.
- **P2 (ignored param)**: `days_threshold` must be read in the staleness comparison —
  never default-assumed as a constant inside the function body while the parameter
  exists.
- **P7 (error codes)**: Memory decay does not emit error codes directly; vault write
  failures propagate from `upsert_note`.
