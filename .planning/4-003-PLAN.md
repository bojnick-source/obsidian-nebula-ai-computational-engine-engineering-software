## Objective

Create `forge_agent/core/intelligence_router.py` — an `IntelligenceRouter` that wraps
the existing `CircuitBreaker` (from `retry.py`) and `ProviderClients` (from
`provider_clients.py`) to provide automatic failover from a primary provider
(Anthropic) to a secondary provider (OpenAI) when the primary circuit is OPEN
or a call raises an exception.

Then update `PipelineRunner._run_phase_specialist()` to call through
`IntelligenceRouter` instead of calling `self._anthropic_client.messages.create()`
directly. The router is optional — when not provided the pipeline falls back to
its existing `_anthropic_client` path, maintaining 100% backward compatibility.

## Acceptance Criteria

1. `pytest forge_agent/tests/test_intelligence_router.py -v` exits 0.
2. When primary provider raises an exception, `route_call()` catches it, calls
   `record_failure()` on the primary circuit breaker, and retries on the secondary.
3. When primary circuit breaker state is `OPEN` (verified via `allow_call()` returning
   `False`), `route_call()` skips the primary entirely and calls the secondary directly.
4. When primary succeeds, `record_success()` is called and secondary is NOT called.
5. When BOTH primary and secondary fail, `route_call()` raises `RuntimeError` with
   error code `ERR_PROVIDER_UNAVAILABLE` in the message.
6. HALF_OPEN probe guard: when primary circuit is `HALF_OPEN` and `allow_call()`
   returns `True` for the first caller, a second concurrent caller gets `allow_call()`
   returning `False` and is directed to secondary without waiting for the probe.
7. Pipeline with `IntelligenceRouter` injected completes a task using the stub
   specialist path (no real API key required in tests).
8. `route_call()` is async; callers await it.

Pytest command: `pytest forge_agent/tests/test_intelligence_router.py -v`

## Design

### `IntelligenceRouter` class

File: `forge_agent/core/intelligence_router.py`

```python
from __future__ import annotations

import asyncio
from typing import Any

from forge_agent.core.retry import CircuitBreaker, CircuitState
from forge_agent.core.provider_clients import ProviderClients


class IntelligenceRouter:
    """Route LLM calls with automatic failover using per-provider CircuitBreakers.

    Primary provider: Anthropic (claude-opus-4-6 / claude-sonnet-4-6)
    Secondary provider: OpenAI (o3 / gpt-4o)

    Failover triggers when:
      - Primary CircuitBreaker.allow_call() returns False (OPEN or HALF_OPEN + probe in flight)
      - Primary call raises any exception

    Parameters
    ----------
    config:
        Router config dict (same structure as forge.yaml router section).
        Used to resolve model IDs via ProviderClients.resolve_model().
    providers:
        ProviderClients singleton (or injectable mock for testing).
    primary_cb:
        CircuitBreaker instance for the primary (Anthropic) provider.
        If None, a default CircuitBreaker() is created.
    secondary_cb:
        CircuitBreaker instance for the secondary (OpenAI) provider.
        If None, a default CircuitBreaker() is created.
    """

    def __init__(
        self,
        config: dict,
        providers: ProviderClients,
        primary_cb: CircuitBreaker | None = None,
        secondary_cb: CircuitBreaker | None = None,
    ) -> None:
        self._config = config               # used in route_call via resolve_model
        self._providers = providers         # used in route_call for API calls
        self._primary_cb = primary_cb if primary_cb is not None else CircuitBreaker()
        self._secondary_cb = secondary_cb if secondary_cb is not None else CircuitBreaker()

    async def route_call(
        self,
        role: str,
        messages: list,
        **kwargs: Any,
    ) -> dict:
        """Attempt primary provider; failover to secondary on circuit open or error.

        Parameters
        ----------
        role:
            Agent role string passed to ProviderClients.resolve_model() for model selection.
        messages:
            List of message dicts in provider-agnostic format
            [{"role": "user", "content": "..."}].
        **kwargs:
            Extra kwargs forwarded to provider SDK (max_tokens, temperature, system, etc.)

        Returns
        -------
        dict with keys: provider, model, content (str), raw_response (provider object)

        Raises
        ------
        RuntimeError(ERR_PROVIDER_UNAVAILABLE ...) if both providers fail.
        """
        # --- Try primary (Anthropic) ---
        if self._primary_cb.allow_call():
            try:
                result = await self._call_anthropic(role, messages, **kwargs)
                self._primary_cb.record_success()
                return result
            except Exception as primary_exc:
                self._primary_cb.record_failure()
                # Fall through to secondary
                primary_err = str(primary_exc)
        else:
            primary_err = f"Primary circuit breaker {self._primary_cb.state} — skipped"

        # --- Failover to secondary (OpenAI) ---
        if self._secondary_cb.allow_call():
            try:
                result = await self._call_openai(role, messages, **kwargs)
                self._secondary_cb.record_success()
                return result
            except Exception as secondary_exc:
                self._secondary_cb.record_failure()
                raise RuntimeError(
                    f"ERR_PROVIDER_UNAVAILABLE: both providers failed. "
                    f"Primary: {primary_err}. Secondary: {secondary_exc}"
                ) from secondary_exc

        raise RuntimeError(
            f"ERR_PROVIDER_UNAVAILABLE: both circuit breakers open. "
            f"Primary: {primary_err}"
        )

    async def _call_anthropic(self, role: str, messages: list, **kwargs: Any) -> dict:
        model, _ = self._providers.resolve_model(self._config, role)
        response = await self._providers.anthropic.messages.create(
            model=model,
            messages=messages,
            **kwargs,
        )
        return {
            "provider": "anthropic",
            "model": model,
            "content": response.content[0].text,
            "raw_response": response,
        }

    async def _call_openai(self, role: str, messages: list, **kwargs: Any) -> dict:
        # Strip Anthropic-specific kwargs not accepted by OpenAI
        oai_kwargs = {k: v for k, v in kwargs.items() if k not in {"system"}}
        # OpenAI uses system message as first message element
        system = kwargs.get("system")
        oai_messages = messages
        if system:
            oai_messages = [{"role": "system", "content": system}] + list(messages)

        # Resolve OpenAI model from config (fallback to gpt-4o)
        model, _ = self._providers.resolve_model(
            self._config, role + "_openai_fallback"
        )
        if not model or "claude" in model:
            model = "gpt-4o"

        response = await self._providers.openai.chat.completions.create(
            model=model,
            messages=oai_messages,
            **oai_kwargs,
        )
        return {
            "provider": "openai",
            "model": model,
            "content": response.choices[0].message.content,
            "raw_response": response,
        }
```

### CircuitBreaker API (verified from `forge_agent/core/retry.py`)

Confirmed method signatures:
- `allow_call() -> bool` — returns True if CLOSED or HALF_OPEN (first probe only)
- `record_success() -> None` — clears failure count, closes circuit
- `record_failure() -> None` — increments failure count; opens circuit at threshold
- `state` property → `CircuitState` (CLOSED | OPEN | HALF_OPEN)
- HALF_OPEN: `_probe_in_flight=True` after first `allow_call()` → subsequent
  callers get `False` (P3 guard confirmed from retry.py lines 111-116)

Note: `_run_phase_specialist` is currently synchronous. The router call uses
`run_in_executor` + `asyncio.run()` to bridge sync→async within the existing
sync pipeline. An alternative (converting `run()` to async) is deferred to a
future phase to avoid breaking existing callers.

## Known Risks

- `_run_phase_specialist()` is synchronous but `IntelligenceRouter.route_call()` is
  async. The bridge via `run_in_executor` + nested `asyncio.run()` works in CPython
  but may cause issues if the caller is already inside an event loop (e.g., when the
  pipeline is eventually made async). This is flagged as technical debt; a clean fix
  is to make `PipelineRunner.run()` async, deferred to a future plan.
- The `resolve_model()` fallback for OpenAI models returns `"gpt-4o"` as a hardcoded
  safe default if no OpenAI tier is configured in `forge.yaml`. This is acceptable for
  Phase 4 — `forge.yaml` already defines `openai.models.primary = o3`.
- When `self._intelligence_router` is set AND `self._anthropic_client` is set,
  the router takes precedence. This is the intended behavior (router wraps the client).
