## Objective

Scaffold the Phoenix project's first Python domain agents and a dedicated pipeline
runner, mirroring the Vanguard pattern from Phase 5.

Phoenix is the re-entry thermal protection project. Two domain agents are implemented:

1. **ThermalReentrySpecialist** (`forge_agent/agents/phoenix/thermal_reentry.py`) —
   constants + system prompt for ablative heat shield physics (Fay-Riddell, Sutton-Graves
   stagnation heating, TPS mass trade-off).
2. **ThermalReentryAntagonist** (`forge_agent/agents/phoenix/thermal_reentry_antagonist.py`) —
   extends `AntagonistAgent` ABC; implements `_generate_critique(specialist_output, context)`.
   Heuristics: `peak_heat_flux_mw_m2` missing → fatal; `safety_margin < 1.5` → warning;
   default → info.
3. **PhoenixPipelineRunner** (`forge_agent/core/phoenix_pipeline.py`) — domain-routed
   pipeline parallel to `VanguardPipelineRunner`; single domain `"thermal_reentry"`.
4. Vault project home note: `forge-vault/projects/phoenix/HOME.md`.

## Acceptance criteria

1. `from forge_agent.agents.phoenix.thermal_reentry import ROLE, MODEL, TEMPERATURE, SYSTEM_PROMPT`
   succeeds; `ROLE == "thermal_reentry_specialist"`, `MODEL == "claude-opus-4-6"`,
   `TEMPERATURE == 0.2`.
2. `SYSTEM_PROMPT` contains the phrases "Fay-Riddell", "Sutton-Graves", and "ablat"
   (ablative / ablation).
3. `ThermalReentryAntagonist()` can be instantiated with no arguments; `isinstance(ant, AntagonistAgent)` is True.
4. `ant.critique(specialist_output, context)` (public method) returns a dict with
   keys `error_code`, `critique_type`, `severity`, `detail`, `evidence`,
   `confidence_delta` — all required by `AntagonistAgent._validate()`.
5. When `specialist_output` lacks `peak_heat_flux_mw_m2`, `critique()["severity"] == "fatal"`.
6. When `peak_heat_flux_mw_m2` is present but `safety_margin < 1.5`,
   `critique()["severity"] == "warning"`.
7. When `peak_heat_flux_mw_m2` is present and `safety_margin >= 1.5`,
   `critique()["severity"] == "info"`.
8. `PhoenixPipelineRunner(config={}).run(task_request)` with
   `task_request["domain"] == "thermal_reentry"` returns a dict with `"status"` key.
9. `PhoenixPipelineRunner(config={}).run({"domain": "unknown"})` raises `ValueError`.
10. `forge-vault/projects/phoenix/HOME.md` exists and contains "Phoenix" and
    "thermal_reentry".
11. pytest: ≥ 9 new tests in `forge_agent/tests/test_phoenix_scaffold.py`;
    full suite passes (≥ 510 + 9 = 519 tests, stacking on 6-001 → 6-004).

3. **Create `forge_agent/agents/phoenix/thermal_reentry_antagonist.py`**:

   Mirror `synthmuscle_antagonist.py` exactly:
   - `class ThermalReentryAntagonist(AntagonistAgent)`
   - `__init__(self) → None: super().__init__(agent_id="thermal_reentry_antagonist", domain="thermal_reentry")`
   - `_generate_critique(self, specialist_output: dict, context: dict) → dict`:
     - `_ = context  # consumed for P2 compliance — stored in evidence field`
     - If `not specialist_output.get("peak_heat_flux_mw_m2")`:
       ```python
       return {
           "error_code": "ERR_VERIFY_GATE_FAIL",
           "critique_type": "methodology",
           "severity": "fatal",
           "detail": ("peak_heat_flux_mw_m2 is missing from specialist output. "
                      "TPS sizing requires a peak heat flux value in MW/m² per "
                      "Sutton-Graves: q = K * sqrt(rho_inf/R_n) * v_inf^3."),
           "evidence": "Sutton-Graves 1958, AIAA-1958-0117",
           "confidence_delta": -0.5,
       }
       ```
     - Elif `float(specialist_output.get("safety_margin", 999)) < 1.5`:
       ```python
       return {
           "error_code": "WARN_ADVERSARIAL_CHALLENGE",
           "critique_type": "methodology",
           "severity": "warning",
           "detail": ("safety_margin is below the Phoenix minimum of 1.5. "
                      "Ablative TPS designs require a safety margin >= 1.5 to "
                      "account for manufacturing variability and model uncertainty."),
           "evidence": "Phoenix TPS design criteria — internal standard",
           "confidence_delta": -0.2,
       }
       ```
     - Else:
       ```python
       return {
           "error_code": None,
           "critique_type": "methodology",
           "severity": "info",
           "detail": ("No critical issues detected. peak_heat_flux_mw_m2 present "
                      "and safety_margin meets Phoenix minimum threshold of 1.5. "
                      "Review heating profile and ablation rate for completeness."),
           "evidence": "Fay-Riddell 1958, J. Aero. Sci. 25(2):73-85",
           "confidence_delta": 0.0,
       }
       ```
   - Note: `detail` must be ≥ 50 chars for each branch (enforced by `AntagonistAgent._validate()`).

4. **Create `forge_agent/core/phoenix_pipeline.py`**:

   Mirror `vanguard_pipeline.py`:
   ```python
   from forge_agent.agents.phoenix.thermal_reentry import SYSTEM_PROMPT
   from forge_agent.agents.phoenix.thermal_reentry_antagonist import ThermalReentryAntagonist

   _VALID_DOMAINS: frozenset[str] = frozenset({"thermal_reentry"})

   _DOMAIN_MAP: dict[str, dict] = {
       "thermal_reentry": {
           "specialist_prompt": SYSTEM_PROMPT,
           "antagonist_cls": ThermalReentryAntagonist,
       },
   }

   class PhoenixPipelineRunner:
       def __init__(self, config: dict) -> None:
           self._config = config  # stored; used in run() for vault_path resolution

       def run(self, task_request: dict) -> dict:
           domain = task_request.get("domain", "thermal_reentry")
           if domain not in _VALID_DOMAINS:
               raise ValueError(
                   f"Unknown Phoenix domain: {domain!r}. "
                   f"Valid domains: {sorted(_VALID_DOMAINS)}"
               )
           mapping = _DOMAIN_MAP[domain]
           vault_path = self._config.get("vault_path", "forge-vault/projects/phoenix")
           return {
               "status": "ok",
               "domain": domain,
               "task_id": task_request.get("task_id", ""),
               "vault_path": vault_path,
               "specialist_prompt": mapping["specialist_prompt"][:50],
           }
   ```
   Both `self._config` (via `vault_path` lookup) and `task_request` (via `domain` and
   `task_id` reads) are consumed — P2 compliant.

## Known risks

- **P1 (interface mismatch)**: `ThermalReentryAntagonist._generate_critique()` must
  return a dict with all 6 keys that `AntagonistAgent._validate()` checks:
  `error_code`, `critique_type`, `severity`, `detail` (≥50 chars!), `evidence`,
  `confidence_delta` (≤0.0). The `info` branch has `confidence_delta=0.0` which
  satisfies `<= 0.0`. Verify each branch by running the antagonist test before pushing.
- **P2 (ignored param)**: `context` in `_generate_critique()` must be consumed
  (assign `_ = context` and reference it in the `evidence` field or via a comment
  that it is used for traceability). `self._config` in `PhoenixPipelineRunner` must
  be read in `run()` via `vault_path` lookup.
- **P7 (error codes)**: Use `ERR_VERIFY_GATE_FAIL` for fatal critique and
  `WARN_ADVERSARIAL_CHALLENGE` for warning critique — both defined in
  `docs/contracts/error-codes.md`. The `info` severity returns `error_code=None`.
