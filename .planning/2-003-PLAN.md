## Objective

Create `forge_agent/tests/test_v01_acceptance.py` — a pytest test file that
directly exercises the v0.1 acceptance criteria defined in
`docs/planning/mvp/v0.1-acceptance-test.md`.

GMSH and CalculiX binaries are mocked via `unittest.mock` so the tests pass
in CI without external solver installations. Real vault I/O uses a `tmp_path`
pytest fixture (real filesystem, no mocking).

## Acceptance Criteria

1. All 10 acceptance criteria (AC-01 → AC-10) are covered by at least one test.
2. All tests pass: `pytest forge_agent/tests/test_v01_acceptance.py -v` exits 0.
3. Tests use `unittest.mock.patch` to replace GMSH/CalculiX subprocess calls;
   mock returns a valid MCP Wrapper Envelope v1 success response.
4. Real `run_all_gates()` is called (not mocked) to verify the verification
   stack actually runs.
5. Real `ObsidianVaultManager` is used with `tmp_path` vault directory.
6. Test `test_ac09_vault_blocked_on_gate_failure` confirms that injecting an
   invalid specialist output (missing equations) causes `TaskResult.status
   == "failed"` and vault write is NOT called.
7. Full regression suite still passes: `pytest --tb=short -q` exits 0.
