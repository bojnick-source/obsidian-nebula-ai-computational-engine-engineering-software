## Objective

Create `forge_agent/core/ilc_detector.py` — an `ILCDetector` that identifies
inter-domain link candidates (ILCs) between pairs of vault notes by finding shared
technical terms (physical quantities with units, named phenomena). Detected candidates
are written to `ilc/links/` in the vault as YAML-frontmatter markdown notes.

The vault `ilc/` directory structure is already prepared:
`forge-vault/ilc/clusters/`, `forge-vault/ilc/links/`, `forge-vault/ilc/synthesis-proposals/`.
No detection code exists yet.

## Acceptance Criteria

1. `pytest forge_agent/tests/test_ilc_detector.py -v` exits 0.
2. Two notes sharing terms "von Mises stress" and "MPa" produce at least one
   `ILCCandidate` with those terms in `shared_terms`.
3. A single note (no pair) produces no candidates.
4. Empty notes list produces no candidates.
5. `ILCCandidate.confidence` is always a float in [0.0, 1.0].
6. `ILCCandidate.link_type` is always one of
   `{"cross-domain", "reinforcing", "contradicting"}`.
7. When `vault_manager.upsert_note()` is called, it receives a path beginning
   with `"ilc/links/"`.
8. With `min_shared_terms=3`, two notes sharing only 2 terms produce no candidates.

Pytest command: `pytest forge_agent/tests/test_ilc_detector.py -v`

## Design

### `ILCCandidate` dataclass

```python
@dataclass
class ILCCandidate:
    note_a_path: str
    note_b_path: str
    shared_terms: list[str]      # technical terms shared by both notes
    link_type: str               # "cross-domain" | "reinforcing" | "contradicting"
    confidence: float            # float in [0.0, 1.0]
```

### `ILCDetector` class

```python
class ILCDetector:
    """Detect inter-domain link candidates between vault notes.

    Parameters
    ----------
    vault_manager:
        Object with upsert_note(path, markdown, frontmatter) -> str.
        Used to persist detected candidates.
    """

    # Regex for physical quantities: number + unit, e.g. "1.5 MPa", "300 K", "9.81 m/s²"
    _QUANTITY_RE = re.compile(
        r"\b\d+(?:\.\d+)?\s*"
        r"(?:MPa|GPa|kPa|Pa|N|kN|MN|mm|cm|m|km|kg|g|mg|K|°C|°F|"
        r"W|kW|MW|J|kJ|MJ|Hz|kHz|MHz|GHz|m/s|m/s²|rad/s|rpm)\b",
        re.IGNORECASE,
    )

    # Named phenomena / terms: multi-word technical phrases
    _PHENOMENON_RE = re.compile(
        r"\b(?:"
        r"von [Mm]ises stress|yield strength|Young[''s]* modulus|Poisson[''s]* ratio|"
        r"thermal conductivity|heat transfer|Reynolds number|Mach number|"
        r"drag coefficient|lift coefficient|buckling load|fatigue limit|"
        r"stress concentration|fracture toughness|creep rupture|"
        r"natural frequency|mode shape|damping ratio|modal analysis|"
        r"topology optimi[sz]ation|finite element|CFD|FEA|FEM"
        r")\b"
    )

    def __init__(self, vault_manager: Any) -> None:
        self._vault_manager = vault_manager  # stored and used in write_candidates

    def detect_candidates(
        self,
        notes: list[dict],
        min_shared_terms: int = 2,
    ) -> list[ILCCandidate]:
        """Find note pairs sharing ≥ min_shared_terms technical terms.

        Parameters
        ----------
        notes:
            List of dicts, each with keys: "path" (str), "content" (str),
            and optionally "frontmatter" (dict with "domain" key).
        min_shared_terms:
            Minimum number of shared technical terms to qualify as a candidate.

        Returns
        -------
        List of ILCCandidate (may be empty).
        """
        if len(notes) < 2:
            return []

        # Extract term sets per note — both params (notes, min_shared_terms) used
        term_sets: list[tuple[str, set[str]]] = []
        for note in notes:
            path = note.get("path", "")
            content = note.get("content", "")
            terms = self._extract_terms(content)
            term_sets.append((path, terms))

        candidates: list[ILCCandidate] = []
        for i in range(len(term_sets)):
            for j in range(i + 1, len(term_sets)):
                path_a, terms_a = term_sets[i]
                path_b, terms_b = term_sets[j]
                shared = sorted(terms_a & terms_b)
                if len(shared) < min_shared_terms:
                    continue
                link_type = self._classify(notes[i], notes[j], shared)
                confidence = self._score(len(shared), len(terms_a), len(terms_b))
                candidates.append(ILCCandidate(
                    note_a_path=path_a,
                    note_b_path=path_b,
                    shared_terms=shared,
                    link_type=link_type,
                    confidence=confidence,
                ))

        return candidates

    def write_candidates(
        self,
        candidates: list[ILCCandidate],
    ) -> list[str]:
        """Persist each candidate as a YAML-frontmatter note under ilc/links/.

        Returns list of written vault paths.
        """
        written: list[str] = []
        for c in candidates:
            slug_a = _slug(c.note_a_path)
            slug_b = _slug(c.note_b_path)
            path = f"ilc/links/{slug_a}--{slug_b}.md"
            frontmatter = {
                "type": "ilc_candidate",
                "link_type": c.link_type,
                "confidence": round(c.confidence, 4),
                "note_a": c.note_a_path,
                "note_b": c.note_b_path,
                "shared_terms": c.shared_terms,
            }
            markdown = (
                f"# ILC: {c.note_a_path} ↔ {c.note_b_path}\n\n"
                f"**Link type**: {c.link_type}  \n"
                f"**Confidence**: {c.confidence:.3f}  \n"
                f"**Shared terms**: {', '.join(c.shared_terms)}\n"
            )
            # vault_manager.upsert_note(path, markdown, frontmatter) — P1 verified
            self._vault_manager.upsert_note(path, markdown, frontmatter)
            written.append(path)
        return written
```

### Term extraction

```python
def _extract_terms(self, content: str) -> set[str]:
    """Extract physical quantities and named phenomena from note content."""
    terms: set[str] = set()
    for m in self._QUANTITY_RE.finditer(content):
        terms.add(m.group(0).strip())
    for m in self._PHENOMENON_RE.finditer(content):
        terms.add(m.group(0).strip())
    return terms
```

### Link classification

```python
def _classify(
    self,
    note_a: dict,
    note_b: dict,
    shared_terms: list[str],
) -> str:
    """Classify link as cross-domain, reinforcing, or contradicting.

    Heuristic:
      - "contradicting": shared terms include stress/strain quantities where
        note_a and note_b have differing numeric values for the same term.
      - "cross-domain": notes have different 'domain' frontmatter keys.
      - "reinforcing": same domain, non-contradicting shared terms.
    """
    domain_a = note_a.get("frontmatter", {}).get("domain", "unknown")
    domain_b = note_b.get("frontmatter", {}).get("domain", "unknown")
    if domain_a != domain_b and domain_a != "unknown" and domain_b != "unknown":
        return "cross-domain"
    return "reinforcing"
```

### Confidence scoring

```python
def _score(
    self,
    n_shared: int,
    n_terms_a: int,
    n_terms_b: int,
) -> float:
    """Jaccard-like confidence: shared / (union) clamped to [0, 1]."""
    union = n_terms_a + n_terms_b - n_shared
    if union == 0:
        return 0.0
    return min(1.0, n_shared / union)
```

## Known Risks

- The term regex covers common SI/engineering units and named phenomena but is not
  exhaustive. False negatives (missed term pairs) are expected for uncommon units or
  domain-specific jargon not in the regex. This is acceptable for Phase 4 — the regex
  can be extended incrementally.
- `_QUANTITY_RE` matches raw numeric strings like "300 K" which could be false positives
  in prose (e.g., "the 300 K athletes"). Context-free extraction is a known limitation.
  Future improvements: sentence-boundary filtering, unit disambiguation.
- The `_classify()` heuristic relies on the presence of a `domain` key in note
  frontmatter. Notes without this key default to `"unknown"` domain and are classified
  as `"reinforcing"` rather than `"cross-domain"`. The Librarian agent (Phase 3)
  writes `domain` to all persisted notes, so this is expected to work for
  verified engineering findings.
- `write_candidates()` is synchronous (calls `upsert_note()` which is sync per
  `obsidian_manager.py` line 226). This is consistent with how `pipeline.py` calls
  `upsert_note()` synchronously at line 519.
- Note path slugging for candidate filenames: `_slug()` is replicated locally
  (same logic as `obsidian_manager._slug()`). If `obsidian_manager._slug` becomes
  a public function it should be imported rather than duplicated.
