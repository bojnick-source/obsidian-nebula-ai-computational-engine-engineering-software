## Objective

Implement `forge_agent/agents/librarian.py` — the Python runtime for the
Librarian agent (defined in `forge-agents/librarian/SKILL.md`).

The Librarian is the gatekeeper between the live blackboard and the persistent
Obsidian vault. It is required by v0.1 acceptance criteria AC-06 (vault
persistence), AC-07 (amnesia check), and is consumed by plan 2-001
(PipelineRunner phase 4 memory_preflight and phase 8 persistence).

## Acceptance Criteria

1. `LibrarianAgent(vault_manager).intake(note_dict) → str` — writes note to
   vault at computed path, returns path string.
2. `LibrarianAgent.retrieve(domain, component, top_k=5) → list[dict]` — returns
   list of matching notes (may be empty list; never raises).
3. `LibrarianAgent.amnesia_check(path) → bool` — returns True if path is
   retrievable immediately after write.
4. `LibrarianAgent.detect_gaps(blackboard: dict) → list[str]` — returns list
   of gap strings (empty list = no gaps detected).
5. Roundtrip test: `intake → retrieve(domain, component) → len > 0` passes
   using a tmp directory vault.
6. All method signatures use only parameters that are actually used in the
   method body (P2 check).
7. `pytest forge_agent/tests/test_librarian.py -q` passes with 0 errors.

## Implementation Steps

1. Create `forge_agent/agents/librarian.py`:
   ```python
   class LibrarianAgent:
       def __init__(self, vault_manager: ObsidianVaultManager) -> None:
           self._vault = vault_manager

       def intake(self, note_dict: dict) -> str:
           """Classify and write note; return vault path."""
           ...

       def retrieve(self, domain: str, component: str, top_k: int = 5) -> list[dict]:
           """Search vault by domain + component filter."""
           ...

       def amnesia_check(self, path: str) -> bool:
           """Return True iff path is immediately retrievable post-write."""
           return self._vault.amnesia_check(path)

       def detect_gaps(self, blackboard: dict) -> list[str]:
           """Identify knowledge gaps from blackboard state."""
           ...
   ```

2. `intake()` implementation:
   - Compute path: `f"projects/{note_dict.get('project','unknown')}/components/{note_dict.get('component','unknown')}/{note_dict.get('trace_id','untitled')}.md"`
   - Call `self._vault.upsert_note(path, markdown_body, frontmatter)` where frontmatter
     includes: type="finding", domain, component, project, trace_id, confidence,
     created_at (ISO 8601)
   - Return path string

3. `retrieve()` implementation:
   - Call `self._vault.search_notes(query=component)` (uses ObsidianVaultManager)
   - Filter results where frontmatter domain matches `domain` and component
     matches `component`
   - Return top_k results as list of dicts

4. `detect_gaps()` implementation:
   - Check blackboard for `"specialist.result"` — if absent or empty, gap: "no specialist output"
   - Check blackboard for `"tool_results.calculix"` — if absent, gap: "no FEA results"
   - Check blackboard for `"verification.status"` — if "failed", gap: "verification failed"
   - Return list of gap strings

5. Create `forge_agent/tests/test_librarian.py`:
   - `test_intake_returns_path` — write note dict, verify path string returned
   - `test_amnesia_check_returns_true_after_write` — intake then amnesia_check
   - `test_retrieve_finds_written_note` — intake then retrieve by domain+component
   - `test_detect_gaps_empty_blackboard` — all gaps detected
   - `test_detect_gaps_complete_blackboard` — no gaps

## Known Risk

- **P1 — Method name mismatch**: `ObsidianVaultManager` exposes `search_notes`,
  `get_note`, `upsert_note`, `amnesia_check`. Verify each name before calling.
  Do not guess async vs sync — check the actual signatures in obsidian_manager.py.
- **P2 — Accepted-but-unused parameters**: `detect_gaps(blackboard)` must
  actually read from `blackboard`. Do not accept it and ignore it.
